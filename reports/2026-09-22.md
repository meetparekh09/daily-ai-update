## Trending Papers

**Q2D-Web: A Large-Scale Benchmark for Retrieval in Agentic RAG Systems** — https://arxiv.org/abs/2609.08887
A benchmark introducing a 190M-document web corpus with 70k agent-reformulated queries across 10 languages, designed to evaluate first-stage retrievers at production scale in agentic RAG pipelines.
*Why it matters for practitioners:* Existing RAG benchmarks have either large corpora with few queries or many queries over small corpora—Q2D-Web closes this gap and finally lets teams measure retriever quality at the scale they actually operate.

**An Interpretable Memory Decision Controller for LLM Agents** — https://arxiv.org/abs/2609.22043
Proposes a memory decision layer using three-signal complementarity—relevance, reliability, and task risk—to decouple confidence from consistency, enabling agents to trustworthily filter conflicting memories in RAG systems.
*Why it matters for practitioners:* Conflicting memory signals are a silent failure mode in production RAG agents; this gives practitioners a principled framework for deciding which memories to trust rather than relying on similarity alone.

**Chronicle: Cut-Point Replay for Regression Testing of LLM Agents** — https://arxiv.org/abs/2609.20625
A regression testing framework for LLM agents that replays conversations from specific cut-points to efficiently detect behavioral regressions when prompts or models change.
*Why it matters for practitioners:* Agent testing has no standard approach comparable to unit tests; Chronicle's cut-point replay means you can validate that a model upgrade didn't break specific agent decision branches without re-running full end-to-end scenarios.

**Authorization Revocation for Long-Running AI Agents** — https://arxiv.org/abs/2609.21284
Addresses the unsolved engineering challenge of revoking credentials and permissions for autonomous agents that execute asynchronously over long time horizons, enabling dynamic permission management for deployed agents.
*Why it matters for practitioners:* Long-running agents that accumulate permissions are a real security liability—this paper provides the first formal treatment of the revocation problem, which will become critical as agents run for hours or days.

**PACT: Can Enterprise AI Assistants Be Trusted Under Pressure?** — https://arxiv.org/abs/2609.18605
An empirical benchmark evaluating enterprise AI assistants under high-stress, time-pressure scenarios to assess whether they maintain reliability and trustworthiness in critical operational contexts (dataset: huggingface.co/datasets/trace-ai-labs/pact).
*Why it matters for practitioners:* Most evals test capability under neutral conditions; PACT reveals failure modes that only emerge under operational pressure—exactly the conditions where enterprise users most need reliability.
