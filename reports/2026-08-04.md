**karpathy/autoresearch** — https://github.com/karpathy/autoresearch

*Why it matters for practitioners:* Demonstrates concretely that the agentic loop can serve as a self-improving ML research pipeline; Karpathy's own 2-day run stacked 20 additive improvements that dropped the Time-to-GPT-2 benchmark from 2.02 to 1.80 hours, showing real (not toy) gains from fully autonomous experimentation.

**infiniflow/ragflow** — https://github.com/infiniflow/ragflow

*Why it matters for practitioners:* Provides a production-grade context layer that handles the full RAG pipeline, letting teams skip building ingestion and retrieval from scratch and focus on task-level agent logic instead.

**karpathy/nanochat** — https://github.com/karpathy/nanochat

## Trending Papers

**Co-Harness: Co-Evolving Harnesses and Model Weights for LLM Agents** — https://arxiv.org/abs/2607.22688
Proposes jointly optimizing the runtime harness (the scaffolding that generates, evaluates, and shapes research trajectories) and model weights during post-training, rather than treating the harness as fixed — submitted July 17, 2026.
*Why it matters for practitioners:* Breaks the tacit assumption that post-training only means updating model parameters; if the harness is jointly trained, changes to your scaffolding after deployment can degrade alignment with what the model learned, and benchmarking should account for harness-weight co-dependence.

**The Interplay of Harness Design and Post-Training in LLM Agents** — https://arxiv.org/abs/2606.25447
Extends ALFWorld to treat the harness (which tools are exposed, how they are described, what auxiliary information accompanies each observation) as a controllable design dimension, and shows that post-training performance varies significantly with harness configuration — submitted June 24, 2026.
*Why it matters for practitioners:* Scaffolding is routinely treated as a static engineering detail and excluded from evaluations; this paper shows that design choices in the harness interact with post-training outcomes, meaning practitioners who ignore harness design are leaving measurable performance on the table.

**SoK: Agentic Retrieval-Augmented Generation (RAG): Taxonomy, Architectures, Evaluation, and Research Directions** — https://arxiv.org/abs/2603.07379
Formalizes agentic RAG systems as finite-horizon partially observable Markov decision processes, develops a taxonomy by planning mechanism, retrieval orchestration, memory paradigm, and tool-invocation behavior, and analyzes failure modes including cascading hallucination, memory poisoning, and retrieval misalignment.
*Why it matters for practitioners:* Provides the rigorous architecture vocabulary that the field has lacked — teams building multi-hop RAG systems can now map their design choices onto a principled taxonomy and identify which systemic risks apply to their setup before hitting them in production.

**SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training** — https://arxiv.org/abs/2606.02355
Introduces a training method where LLM agents learn intrinsic skills via RL and progressively internalize them, reducing reliance on external tool calls for sub-tasks the model can handle internally.
*Why it matters for practitioners:* As agents internalize more capability, they generate fewer external tool calls per task, cutting latency and cost in long-horizon pipelines — this is the kind of training-time efficiency gain that compounds at inference scale.

**Retrospective Progress-Aware Self-Refinement for LLM Agent Training** — https://arxiv.org/abs/2606.14302
Proposes a training signal derived from retrospective analysis of task progress — agents look backward at what improved versus what stalled and use that signal to guide forward refinement steps.
*Why it matters for practitioners:* Standard RL reward signals for agents are sparse and delayed; progress-aware retrospection gives a denser training signal that may be cheaper to implement than process reward models while improving credit assignment across long task horizons.
