*Why it matters for practitioners:* Long-running agentic loops are expensive; 60–90% token reduction translates directly to proportional cost cuts with no architectural changes required.

## Trending Papers

**LLMZero: Discovering Adaptive Training Strategies for RL Post-Training via LLM Agents** — https://arxiv.org/pdf/2606.18388
Uses LLM agents to automatically discover optimal reinforcement learning post-training strategies, replacing manual hyperparameter search with a learned meta-policy.
*Why it matters for practitioners:* Meta-learning the training recipe itself—rather than tuning it by hand—suggests a path where the post-training pipeline becomes largely self-optimizing; a strong update for any team doing RL fine-tuning.

**Beyond Function Calling: Benchmarking Tool-Using Agents under Tool-Environment Unreliability** — https://arxiv.org/pdf/2606.25819
Tests how tool-using agents behave when APIs degrade, tools fail, or responses are malformed, exposing robustness gaps invisible in clean-environment benchmarks.
*Why it matters for practitioners:* Real production environments have flaky APIs; this is the first systematic measure of how agents handle them—and the gaps it finds are likely present in most current stacks.

**In RAG We Trust? Measuring Robustness of Retrieval-Augmented Generation Under Document Poisoning** — https://arxiv.org/abs/2609.09243
Examines how adversarial document tampering and poisoning attacks can compromise RAG system reliability and downstream LLM outputs.
*Why it matters for practitioners:* Any RAG system pulling from open or semi-trusted sources is exposed to this; the threat model is now concrete enough to design defenses rather than ignore.

**ASTRA-bench: Evaluating Tool-Use Agent Reasoning and Action Planning with Personal User Context** — https://arxiv.org/html/2603.01357v1
Introduces 2,413 human-authored conversational scenarios with time-evolving personal context and an interactive tool sandbox (email, calendar, messages) to evaluate complex multi-step agent reasoning.
*Why it matters for practitioners:* Personal-context agents are increasingly shipping in production; this is the first benchmark that evaluates them under the time-varying state those systems actually operate in, rather than static snapshots.

**Scaling with Collapse: Efficient and Predictable Training of LLM Families** — https://arxiv.org/pdf/2509.25087
Proposes techniques for scaling large language model families while maintaining training efficiency and predictability across model sizes.
*Why it matters for practitioners:* Predictable scaling means fewer expensive training runs that underperform at scale—directly lowers the iteration cost of maintaining a family of model sizes for different deployment tiers.
