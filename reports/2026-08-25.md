## Trending Papers

**Demystifying Agent Skills: Why They Work—Until They Don't** — https://arxiv.org/abs/2608.14036
An empirical analysis across 8,135 normalized trials finding that skills stabilize agent action (procedural anchoring: 65.7% of benefit) rather than inject missing knowledge (4.5%), but degrade sharply as skill pool size grows — top-1 retrieval precision falls from 88.3% at pool size 5 to 76.9% at pool size 100.
*Why it matters for practitioners:* If you maintain a skill library for your agents, this paper reveals the exact retrieval-degradation curve and shows that skill misapplication (10% of cases) outstrips knowledge injection as the primary failure mode — pointing to retrieval architecture, not skill content, as the key lever.

**Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory** — https://arxiv.org/abs/2608.07169
A training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through three complementary memory types: Workflow (task-level strategy), Subtask (concrete behavioral examples), and Function (per-function calling conventions and pitfalls).
*Why it matters for practitioners:* This enables smaller, cheaper models to inherit the behavioral expertise of larger ones without retraining — directly relevant to anyone building cost-efficient agent deployments where a frontier model isn't always affordable.

**Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements** — https://arxiv.org/abs/2608.17310
An evolution strategy framework that achieves full-parameter fine-tuning of a 27B-parameter model for long-horizon agentic tasks using only inference-level GPU memory, outperforming Agentic GRPO on DAPO, AIME 2026, and DocVQA.
*Why it matters for practitioners:* RL-based agent fine-tuning has been bottlenecked by backpropagation memory costs and credit-assignment difficulty over long horizons; ESOpt breaks both constraints, making full-parameter agent training accessible on commodity hardware.

**Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning** — https://arxiv.org/html/2508.19828v2
An RL fine-tuned agent framework with a Memory Manager and an Answer Agent, applying a Memory Distillation policy to filter and consolidate RAG-retrieved content before acting.
*Why it matters for practitioners:* By training the memory management decision itself via RL rather than hand-crafting retrieval heuristics, Memory-R1 offers a path toward agents that learn what to remember — a key unsolved problem for long-running, stateful agents.

**A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces** — https://arxiv.org/abs/2602.03442
An agentic RAG framework that exposes three hierarchical retrieval tools to the model — keyword search, semantic search, and chunk read — letting the agent adaptively choose retrieval granularity rather than applying a fixed pipeline.
*Why it matters for practitioners:* Giving the model agency over how it retrieves (not just what it retrieves) addresses the brittleness of fixed retrieval pipelines in multi-hop and domain-crossing queries, and the state-of-the-art results on multi-hop QA make it an immediately applicable architectural pattern.
