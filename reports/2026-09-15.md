## Trending Papers

**AsyncFlow: An Asynchronous Streaming RL Framework for Efficient LLM Post-Training** — https://arxiv.org/abs/2507.01663
Decouples rollout, reward, and update steps into asynchronous pipelines to speed up reinforcement-learning fine-tuning of large language models.
*Why it matters for practitioners:* Synchronous RL training leaves GPUs idle between rollout and update phases; AsyncFlow's pipeline design materially cuts wall-clock time on post-training runs, changing how teams budget and schedule RL compute.

**Mitigating Emergent Collusion in LLM Pricing Agents** — https://arxiv.org/abs/2609.13037
Identifies and mitigates implicit price-fixing behavior that arises when multiple LLM-based agents compete in the same marketplace without any explicit communication.
*Why it matters for practitioners:* If agent collusion can emerge from LLM reasoning alone, any multi-agent market simulation or competitive deployment is subject to unintended coordination — a fundamental assumption about agent independence that needs to be designed around from the start.

**A2ABreak: Systematic Security Analysis of the A2A Protocol** — https://arxiv.org/abs/2609.10871
First structured security evaluation of the Agent-to-Agent communication protocol, cataloguing injection, spoofing, and privilege-escalation attack surfaces.
*Why it matters for practitioners:* As A2A solidifies as the de facto inter-agent communication standard, understanding its attack surfaces before widespread adoption is far cheaper than retrofitting security into deployed agent networks.

**Maverick: Private and Verifiable LLM Inference Made Practical via Matrix-Vector Multiplication Delegation** — https://arxiv.org/abs/2609.10264
Enables a client to cryptographically verify that a server ran the correct LLM weights using lightweight proofs built on delegated matrix-vector multiplications, without trusted hardware assumptions.
*Why it matters for practitioners:* Regulatory and enterprise deployments increasingly require proof that the agreed-upon model ran on the agreed-upon inputs; Maverick is the first approach that makes this practical at real model scales.

**Mr.LHDR: A Benchmark for Multimodal Real-World Long-Horizon Deep Research Agents** — https://arxiv.org/abs/2609.11318
Tests agents on multi-step research tasks requiring integrated text, images, tables, and external retrieval over many sequential decisions in realistic settings.
*Why it matters for practitioners:* Most agent benchmarks test isolated tool-use; a benchmark requiring integrated multimodal retrieval over long horizons surfaces failure modes that practitioners running research or analysis agents actually encounter in production.
