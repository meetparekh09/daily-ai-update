## Trending Papers

**Demystifying Agent Skills: Why They Work—Until They Don't** — https://arxiv.org/abs/2608.14036
The HuggingFace #1 trending paper today (arXiv:2608.14036); through 8,135 controlled trial records across multiple benchmarks and agent harnesses, it isolates exactly which conditions make packaged skills effective and where they systematically break.
*Why it matters for practitioners:* The controlled ablations of representation, retrieval difficulty, and cross-framework robustness give concrete answers to "when should I reach for a skill pack vs. something else"—actionable guidance that most teams currently navigate by intuition.

**Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements** — https://arxiv.org/abs/2608.17310
Uses evolution strategies (ES) for full-parameter fine-tuning of long-horizon agents via trajectory-level reward-weighted updates and parameter-context co-evolution, requiring only inference-level GPU memory throughout training.
*Why it matters for practitioners:* It breaks the assumption that agentic fine-tuning needs expensive RL infrastructure—teams that can run inference can now run full-parameter agent fine-tuning, fundamentally lowering the barrier to on-policy adaptation.

**StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction** — https://arxiv.org/abs/2605.06642
Presented at ICLR 2026; samples a compact strategy from the initial task state, conditions all subsequent actions on it, and trains strategy generation and execution jointly via a hierarchical GRPO-style rollout with diverse strategy rollout and self-judgment.
*Why it matters for practitioners:* The strategy-conditioning design is a transferable architectural pattern that consistently improves sample efficiency over baselines on ALFWorld, WebShop, and SciWorld, suggesting a reusable template for agentic RL training pipelines.

**Agent-Omit: Training Efficient LLM Agents for Adaptive Thought and Observation Omission via Agentic Reinforcement Learning** — https://arxiv.org/abs/2602.04284
Trains agents to adaptively skip redundant internal thoughts and irrelevant observations during multi-turn interactions using a dual-sampling mechanism and an explicit omission reward signal.
*Why it matters for practitioners:* Inference latency and cost in multi-turn agents come largely from unnecessary context accumulation; training the agent itself to prune that context is more robust than static truncation heuristics applied post-hoc.

**A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces** — https://arxiv.org/abs/2602.03442
Introduces hierarchical retrieval interfaces that let agentic RAG systems scale by decomposing retrieval queries across layers of granularity rather than flattening all documents into a single flat vector index.
*Why it matters for practitioners:* Context efficiency is the binding constraint when integrating RAG into complex agentic workflows; the hierarchical interface design offers a concrete pattern for maintaining relevance precision as corpus size grows.
