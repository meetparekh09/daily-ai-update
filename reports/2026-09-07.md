## Trending Papers

**Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems** — https://pi.snu.ac.kr/news/news/papers/2026/08/21/emnlp-accept.html
Accepted at EMNLP 2026; introduces a gated routing mechanism that lets multi-agent LLM systems selectively share and retain relevant context rather than broadcasting everything.
*Why it matters for practitioners:* Uncontrolled context sharing between agents is both expensive and noisy; gated routing cuts communication overhead while improving task performance, making it directly applicable to any production multi-agent system.

**Gradients Know What Outcomes Don't: Unlocking Reinforcement Learning for LLM Reasoning with Gradient-Aligned Rewards** — https://arxiv.org/abs/2609.03342
Proposes Gradient-Aligned Reward (GAR), a reward signal for RLVR that operates in the policy's gradient space rather than solely on outcome-level signals.
*Why it matters for practitioners:* Outcome-level rewards are often too sparse to efficiently guide reasoning improvement; GAR provides a denser training signal that should accelerate RLVR training for anyone working on reasoning-capable models.

**The Periodic Table of LLM Reasoning: A Structured Survey of Reasoning Paradigms, Methods, and Failure Modes** — https://arxiv.org/pdf/2606.11470
Organizes the LLM reasoning literature into a periodic-table-style taxonomy covering chain-of-thought, tree search, tool use, and known failure modes.
*Why it matters for practitioners:* A well-structured map of which reasoning techniques exist, where each fits, and where each breaks — the reference to reach for before choosing how to add reasoning to a system.

**HBQ: Hierarchical Scaling Block Quantization** — https://arxiv.org/abs/2609.00450
A hierarchical block-level quantization scheme for efficient LLM inference, accepted to MICRO 2026.
*Why it matters for practitioners:* Memory and compute costs remain the primary constraint on deploying large models; HBQ's block-level approach offers a practical path to meaningful reduction without accuracy degradation.

**The Rise of Verbal Reinforcement Learning** — https://arxiv.org/abs/2609.01597
Defines Verbal Reinforcement Learning (VRL), a paradigm where natural-language critique — rather than scalar reward — is the primary feedback signal for improving language agents.
*Why it matters for practitioners:* VRL reframes how you train agents when you can specify feedback as text rather than a numeric reward; any team working on human-in-the-loop agent training should understand this framing.
