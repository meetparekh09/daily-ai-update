## Trending Papers

**MDPO: Overcoming the Training-Inference Divide of Masked Diffusion Language Models** — https://arxiv.org/abs/2508.13148
Frames the denoising trajectory of masked diffusion LMs as a sequential decision problem and applies reinforcement learning to it, enabling models to produce direct answers in a few steps rather than explicit step-by-step chains.
*Why it matters for practitioners:* Closes the training/inference gap that has limited masked diffusion LMs in latency-sensitive production settings, making them a credible alternative to autoregressive models for inference-heavy agent loops.

**Masked Diffusion Language Models are Strong and Steerable Text-Based World Models for Agentic RL** — https://arxiv.org/abs/2607.16204
Shows that masked diffusion LMs achieve better coherence, groundedness, and rollout diversity than autoregressive LLMs 4× their parameter count, with up to 47% absolute gains across out-of-distribution agent environments via a plug-and-play GRPO framework.
*Why it matters for practitioners:* Challenges the default assumption that autoregressive LLMs are the right backbone for world models in RL agent training—smaller, cheaper MDLMs outperform on the metrics that matter for agent rollouts.

**OneDayAgent: Towards a Long-Horizon Harness for Autonomous Agents** — https://arxiv.org/abs/2608.05013
A new benchmark harness accepted at NGEN-AI 2026 that evaluates autonomous agents on multi-step tasks spanning a full simulated workday, exposing drift, context loss, and error propagation at scale.
*Why it matters for practitioners:* Existing evals test short-horizon tasks; this harness directly measures the failure modes that matter for production long-running agents.

**Adversarial Intent is a Latent Variable: Stateful Trust Inference for Securing Multimodal Agentic RAG** — https://arxiv.org/pdf/2602.21447
Proposes treating adversarial intent as a latent variable in multimodal RAG agents and building a stateful trust inference layer that detects adversarial inputs across modalities at runtime.
*Why it matters for practitioners:* As agents pull from more external sources, stateless input filters fail; this paper shows that modeling trust as session-level state catches attacks that single-turn guardrails miss.

**Benchmark Test-Time Scaling of General LLM Agents** — https://arxiv.org/abs/2602.18998
Rigorously evaluates how allocating more compute at inference time (test-time scaling) affects general-purpose LLM agents on open-ended tasks.
*Why it matters for practitioners:* Quantifies which categories of agent tasks actually benefit from spending more at inference—directly informing production budget allocation decisions.
