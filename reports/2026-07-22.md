## Trending GitHub Repositories

**Colibri** — <https://github.com/JustVugg/colibri>
A 1,300-line pure-C, zero-dependency inference engine that streams GLM-5.2 (744B MoE parameters) off a consumer NVMe SSD, keeping only 9.9 GB of dense layers in RAM and loading routed experts on demand — so the 744B model runs on a 25 GB laptop.
*Why it matters for practitioners:* If you've been treating "need 8×H100s" as a hard constraint for frontier-scale MoE inference, colibri breaks that assumption entirely; it opens a viable path for local, private, offline use of models in the 700B+ class without GPU clusters.

**nanochat** — <https://github.com/karpathy/nanochat>
Andrej Karpathy's minimal single-file LLM training harness covering tokenization, pretraining, SFT, RL, evaluation, KV-cache inference, and a ChatGPT-style web UI — with a single `--depth` integer that auto-configures all hyperparameters to be compute-optimal.
*Why it matters for practitioners:* Training a GPT-2-class model now costs ~$73 on spot instances with this repo, making it the most compact end-to-end reference for anyone who needs to understand or reproduce the full modern training stack rather than just fine-tune.

**Graphify** — <https://github.com/Graphify-Labs/graphify>
Converts an entire codebase (plus PDFs, images, and video) into a queryable knowledge graph spanning 36 tree-sitter grammars, reporting up to 71.5× token reduction on structural queries compared to raw file context.
*Why it matters for practitioners:* Agent coding loops that currently re-read whole files on every turn can swap in a Graphify graph as a persistent, structured memory layer — the token reduction is large enough to meaningfully change what fits in a coding agent's context window.

**OmniRoute** — <https://github.com/diegosouzapw/OmniRoute>
A free, MIT-licensed AI gateway providing a single OpenAI-compatible endpoint routing across 268 providers (50+ free) with an 18-strategy auto-fallback engine, 15–95% token compression, and MCP/A2A support.
*Why it matters for practitioners:* Building resilient multi-model agent pipelines without paying per-call overage or hand-coding fallback logic just got significantly easier — OmniRoute's compression alone can shrink input costs by an order of magnitude on verbose agent traces.

**ktransformers** — <https://github.com/kvcache-ai/ktransformers>
A flexible framework for heterogeneous CPU+GPU LLM inference and fine-tuning, with day-zero support for MoE models and intelligent expert scheduling that keeps hot experts on GPU while offloading cold ones to CPU in BF16/FP8.
*Why it matters for practitioners:* Teams running large MoE models on heterogeneous on-prem hardware finally have a maintained, production-oriented framework for expert scheduling — relevant to anyone serving Qwen3-Coder, GLM, or similar MoE models without a full GPU stack.

## Trending Papers

**SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning** — <https://arxiv.org/abs/2607.14777>
Introduces a training loop where the current policy both collects on-policy trajectories and extracts hindsight skills from them; SEED re-scores sampled actions under ordinary vs. skill-augmented contexts, converting the skill-induced probability shift into a dense token-level distillation signal jointly optimized with outcome-based RL.
*Why it matters for practitioners:* SEED shows that on-policy distillation and RL don't need to be separate training stages — combining them in a single loop consistently improves sample efficiency and generalizes to unseen agent scenarios, offering a cleaner training recipe for anyone building or fine-tuning agentic models.

**Self-GC: Self-Governing Context for Long-Horizon LLM Agents** — <https://arxiv.org/abs/2607.00692>
Treats agent context objects (user turns, tool spans, skill state) as garbage-collectible items — a side-channel planner proposes fold, mask, and prune actions with recoverable sidecars and cache-aware commits, pruning 43.95% of prefix tokens while leaving 84.85% of future continuations unaffected.
*Why it matters for practitioners:* In a production A/B test, Self-GC reduced daytime average input tokens by 10–20% at peak — this is a production-validated, deployable context-management architecture rather than a lab result, directly applicable to any agent running long multi-step tasks.

**CUA-Gym: Scaling Verifiable Training Environments and Tasks for Computer-Use Agents** — <https://arxiv.org/abs/2605.25624>
Introduces a large-scale gym of verifiable computer-use tasks and environments (desktop app interactions, web navigation, file manipulation) with automatic success verification, designed as a training data generation pipeline for computer-use agents.
*Why it matters for practitioners:* The main bottleneck for training computer-use agents has been the absence of scalable, verifiable reward signals — CUA-Gym provides the infrastructure to generate training data at scale, which is the missing piece between "demo-capable" and "production-ready" computer-use agents.

**Fine-Tuning Language Models with Retrieval-Augmented Generation** — <https://arxiv.org/abs/2510.01375>
Presented at ICLR 2026: constructs training trajectories from successful RAG-augmented agent rollouts, then strips the retrieval hints from the student's input so the student learns retrieval-induced reasoning behavior rather than relying on explicit context at inference time.
*Why it matters for practitioners:* This is a practical distillation recipe for making smaller models behave like they have retrieval access even without it — a useful technique for teams that need compact, fast models but want to preserve the quality gains from RAG pipelines.

**Act As a Real Researcher: Benchmarking Frontier LLMs and Agentic Harnesses in the Research Lifecycle** — <https://arxiv.org/abs/2606.07462>
A benchmark suite that evaluates LLMs and multi-agent harnesses across the full research lifecycle — hypothesis generation, literature search, experiment design, data analysis, and paper writing — with verifiable, reproducible evaluation criteria.
*Why it matters for practitioners:* The benchmark exposes where current agentic harnesses break down in realistic long-horizon research workflows (not toy tasks), giving teams that build research-adjacent agents a clearer sense of where to invest improvement effort.
