## Trending Papers

**Reframe: Observation-Aligned Multi-Teacher On-Policy Distillation for Agentic Visual Reasoning** — https://huggingface.co/papers
A training method that distills multiple teacher signals into a student agent using on-policy rollouts, specifically targeting visual reasoning in agentic settings.
*Why it matters for practitioners:* On-policy distillation applied to multi-modal agents addresses the distribution shift problem that makes offline distillation brittle; this is a concrete recipe for making visual agents more robust without collecting new human labels.

**TokenEconomizer: Experience-Driven Black-Box Cost Control for Coding Agents** — https://arxiv.org/abs/2610.22732
An open-source plugin from UC Berkeley and Microsoft Research that cuts coding-agent token costs by 18–31% across five agent-model combinations on SWE-Bench, while also improving Pass@1 in four of five cases.
*Why it matters for practitioners:* The plugin works as an external controller that injects operational micro-skills, prunes persistently irrelevant tools, and exits unproductive failure loops — it requires no model changes and can be dropped into an existing agent pipeline today.

**ShiftRAG: Bypassing the Textual Bottleneck via Decoupled Learning and Continuous Soft Tokens** — https://neurips.cc/virtual/2026/poster/150524
A NeurIPS 2026 paper that decouples retrieval learning from generation in a single-backbone LLM, projecting retrieval alignments into continuous soft tokens to give the generator a richer signal from the retrieval side.
*Why it matters for practitioners:* Standard RAG pipelines bottleneck on text round-trips between retriever and generator; this architecture keeps everything in the latent space and significantly outperforms state-of-the-art on both retrieval and QA, which is a meaningful architecture update for anyone building RAG systems.

**Direct On-Policy Distillation** — https://huggingface.co/papers
A training approach that keeps the student on-policy throughout distillation, avoiding the covariate shift that plagues behavior-cloning-style teacher-student setups.
*Why it matters for practitioners:* On-policy distillation is in a rapid refinement phase right now — teams using this pattern for fine-tuning cheaper models on top of frontier behavior will want to track the specific tricks that make on-policy stay stable.

**StepBack: Self-Consistency Sampling for Chain-of-Thought Reasoning** — https://arxiv.org/list/cs.CL/new
A test-time technique that samples many complete reasoning trajectories within a fixed budget and applies a self-consistency aggregation step to improve final-answer reliability.
*Why it matters for practitioners:* Better reasoning on a fixed compute budget — without changing the model — is the highest-leverage inference-time optimization; this gives a systematic framework for how much sampling buys you, and when it stops helping.
