## Trending Papers

**Trace-Tuned Routing for Cost-Efficient Agentic Workflows** — https://arxiv.org/abs/2611.33402
Proposes a routing layer that uses execution traces from prior runs to steer tasks to cheaper models without quality loss in multi-step agent pipelines.
*Why it matters for practitioners:* Directly addresses inference cost in production multi-step agents; trace-based routing can cut costs without retraining any model in the stack.

**JHiMA-WebRL: Hierarchical Multi-Agent Reinforcement Learning for Long-Horizon Web Tasks** — https://arxiv.org/abs/2611.05263
Introduces a hierarchical multi-agent RL framework where a manager agent decomposes long-horizon web tasks and delegates subtasks to specialist worker agents.
*Why it matters for practitioners:* Long-horizon task completion is where most single-agent systems fail; the hierarchical decomposition pattern here is directly applicable to production automation workflows.

**SpecPilot: Autonomous Algorithm Discovery and Systems Optimization for Speculative Decoding** — https://arxiv.org/abs/2611.02501
An agentic loop that searches over algorithm and hardware configurations to find optimized speculative decoding schedules for a target model.
*Why it matters for practitioners:* Automates the most opaque part of inference optimization, turning speculative decoding setup from a manual systems task into a self-tuning process.

**Sparse Autoencoder Attribution Graphs for LLM Mechanistic Interpretability** — https://arxiv.org/abs/2611.00606
Builds attribution graphs from sparse autoencoder features to trace how specific concepts propagate through a model's forward pass.
*Why it matters for practitioners:* Provides a tool for understanding why a model is producing unexpected outputs, which is especially useful for debugging failures in long-context and agent reasoning chains.

**Runtime Governance Proposal for Tool-Using AI Agents** — https://arxiv.org/abs/2611.26966
Proposes a governance layer that monitors and constrains tool calls made by AI agents at runtime, enforcing policy without modifying the underlying model.
*Why it matters for practitioners:* Policy enforcement at the tool-call layer is easier to maintain than trying to alignment-tune agent behavior; this gives a blueprint for deploying agents in regulated or high-stakes environments.
