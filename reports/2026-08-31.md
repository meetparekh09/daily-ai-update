## Trending Papers

**Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements** — https://arxiv.org/abs/2608.17310
Proposes using evolution strategies (ES) instead of RL for fine-tuning long-horizon LLM agents, enabling full-parameter optimization with a fraction of the GPU memory RL requires.
*Why it matters for practitioners:* Changes the calculus on what hardware you need to fine-tune capable agents — if ES achieves comparable gains (the paper reports +13.7 avg points on Math and DocVQA), teams without large GPU budgets can now seriously attempt agent fine-tuning.

**Why RAGs Hallucinate: Penalty-Aware Evaluation of RAG Systems with Knowledge-Gap Canaries** — https://arxiv.org/abs/2608.26385
Shows that standard volume-based accuracy metrics reward RAG systems for guessing on unknown questions; proposes asymmetric scoring with planted knowledge-gap canaries to surface this failure mode.
*Why it matters for practitioners:* If you're reporting RAG accuracy with standard metrics, you may be measuring guessing rate — the canary approach is a drop-in audit that reveals whether your retrieval-generation pipeline is actually using retrieved context.

**Right Answer, Wrong Method: Shortcut Hacking Misleads the Evaluation of LLM Reasoning on Frontier Science Benchmarks** — https://arxiv.org/abs/2608.02442
Finds that 8.2%–44.1% of "correct" answers from frontier models on science benchmarks are reached via numerical search, enumeration, or guessing rather than valid derivations.
*Why it matters for practitioners:* Benchmark scores you're using to choose models are significantly inflated — the paper proposes an automatic judge for detecting hacked solutions that can be applied to any reasoning eval.

**The Reasoning Tax: Token Economics of LLM Reasoning Across Task Types and Deployment Contexts** — https://arxiv.org/abs/2608.26235
Empirically benchmarks token cost versus accuracy trade-offs of chain-of-thought reasoning across 151 model-benchmark runs on 7 task categories.
*Why it matters for practitioners:* Gives concrete per-task-type guidance on when extended reasoning is worth the token spend — math and code benefit substantially, while instruction-following tasks show diminishing returns, enabling smarter routing decisions in production.

**Calibrated Enough to Know, Not Calibrated to Act: Fabricated Evidence Makes LLM Agents Commit to the Unknowable** — https://arxiv.org/abs/2608.27167
Shows that LLM agents will commit to directional calls on fundamentally unpredictable questions when shown professional-looking fabricated evidence — even agents that are well-calibrated verbally.
*Why it matters for practitioners:* A critical safety finding for any agentic pipeline that ingests external documents or tool outputs — your agent may be confident and wrong precisely because it's processing plausible-looking but fabricated data.
