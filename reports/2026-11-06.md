## Trending Papers

**On Turn-Level Best-of-N Sampling for Scaling LLM Agents** — https://arxiv.org/abs/2611.06868
A generator–selector framework that samples multiple candidate actions at each agent turn and picks the best, as a scalable inference-time compute strategy.
*Why it matters for practitioners:* Inference-time scaling has mostly been studied at the response level; applying Best-of-N at the per-turn level is a more granular handle on agent quality that practitioners can tune independently of training.

**StepBack: Step-Level Error-Localized Resampling for Efficient Test-Time Reasoning** — https://arxiv.org/abs/2611.08403
A lightweight verifier flags which reasoning steps are wrong, and only those steps are resampled, making self-consistency up to 4× faster while preserving accuracy.
*Why it matters for practitioners:* Self-consistency is effective but wastes compute by regenerating correct steps along with wrong ones; step-level resampling makes the approach practical for latency-sensitive production systems.

**StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference** — https://arxiv.org/abs/2611.08363
A stratified quantization scheme that places ultra-low-bit weights in cheaper cache tiers and spills only critical statistics, reportedly delivering 2× speedup on 70B-class models with under 0.3% accuracy degradation.
*Why it matters for practitioners:* Serving 70B models cheaply is still a pain point; a hardware-aware quantization approach that respects cache hierarchy rather than treating memory as flat offers a credible path to halving serving costs.

**Task-Efficient Agent Evaluation Using Cached Traces** — https://arxiv.org/abs/2611.06803
Uses previously recorded agent execution traces to estimate full benchmark performance from a small number of tasks, drastically cutting eval cost.
*Why it matters for practitioners:* Running full agent benchmarks on every model version is expensive; trace-based estimation makes continuous eval feasible without a dedicated compute budget.

**Spectral and Subspace Dynamics of LoRA in Supervised Fine-Tuning and Reinforcement Learning** — https://arxiv.org/abs/2611.08414
Tracks how LoRA adapter singular values evolve across SFT and RL training phases, finding that the low-rank subspaces follow qualitatively different trajectories in each phase.
*Why it matters for practitioners:* Most teams apply LoRA identically for SFT and RL fine-tuning; this analysis suggests the two phases need different adapter configurations, which could meaningfully improve alignment and instruction-following quality.
