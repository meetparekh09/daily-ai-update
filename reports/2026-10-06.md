## Trending Papers

**TACO: Ternary Absolute-max Column-wise One-sparse Optimizer for LLM Fine-Tuning** — https://arxiv.org/abs/2610.02199
Replaces AdamW's full optimizer state with one low-precision entry per column, cutting persistent optimizer state 174× and peak training memory 2.9× on OPT-13B with no accuracy loss.
*Why it matters for practitioners:* Full-parameter fine-tuning of 13B+ models on a single GPU has been blocked by optimizer state overhead; TACO makes that practical without gradient-checkpointing hacks.

**AutoCompact: Learning When to Compact Context in Long-Horizon Coding Agents** — https://arxiv.org/abs/2610.02163
Trains a coding agent to decide when to summarize its working context—preserving relevant state while recovering headroom—learned jointly with the task policy via RL, yielding +9.2 absolute points on SWE-bench Verified.
*Why it matters for practitioners:* Teaching an agent to manage its own context is now a concrete, reproducible recipe rather than a prompt-engineering hack, and the gain is large enough to matter in production.

**NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness** — https://arxiv.org/abs/2609.08183
Routes agent calls to a heterogeneous model pool, records interactions as training data, and feeds routing-guided on-policy distillation in a three-stage curriculum—lifting macro-average agent scores from 58.94→64.87 (4B) and 65.60→69.04 (9B).
*Why it matters for practitioners:* The routing-harness-as-teacher pattern is a practical alternative to expensive human annotation and may be the cleanest path to model-in-the-loop recursive self-improvement.

**Mem++: Non-Destructive Memory for Long-Term Organizational LLM Agents** — https://huggingface.co/papers
Extends agent memory systems to support long-horizon organizational workflows without overwriting prior context, making memory reads and writes non-destructive.
*Why it matters for practitioners:* Production agents lose critical context when memory is compacted or overwritten; Mem++'s non-destructive approach is directly applicable to multi-session, customer-facing agent deployments.

**CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents** — https://arxiv.org/abs/2609.26779
An inference-time context compaction strategy for coding agents that reduces token cost while preserving working state, without requiring additional training.
*Why it matters for practitioners:* Complements AutoCompact with a training-free option—useful when you can't fine-tune the base model but still need context management in production coding agents.
