## Trending Papers

**A Formula-Driven Survey and Research Agenda for On-Policy Distillation** — https://arxiv.org/abs/2606.22793
A comprehensive survey unifying the fragmented on-policy distillation literature into a single formula-driven framework, with a structured open research agenda.
*Why it matters for practitioners:* On-policy distillation is rapidly becoming the dominant training paradigm for agentic LLMs; this survey gives practitioners a navigable map of the design space and highlights where the most impactful open problems remain.

**SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning** — https://arxiv.org/abs/2607.14777
A method where an agentic system iteratively refines its own training signal via self-generated rollouts, eliminating dependence on a fixed teacher model.
*Why it matters for practitioners:* Removing the fixed-teacher constraint breaks the ceiling on distillation quality — this is a meaningful step toward continuously improving agent systems that don't require expensive teacher runs at every training iteration.

**DART-SD: Diamond-Topology Aware Retrieval and Tuning for Self-Distillation of Multi-Turn Tool-Calling Agents** — https://huggingface.co/papers (COLM 2026, search "DART-SD")
A self-distillation method using retrieved hindsight trajectories with diamond-topology routing to improve multi-turn, tool-calling agent performance; accepted at COLM 2026.
*Why it matters for practitioners:* Multi-turn tool-calling is where most production agents fail; this paper directly targets that failure mode with a principled, data-efficient training approach at a top venue.

**Osprey: Production-Ready Agentic AI for Safety-Critical Control Systems** — https://arxiv.org/abs/2508.15066
A four-part agentic framework (plan-first orchestration, data coordination, dynamic tool selection, protocol-agnostic connectors) with mandatory human oversight on hardware writes, deployed at a particle accelerator and wind farm.
*Why it matters for practitioners:* Most agentic AI papers stay in sandbox settings — Osprey is a rare, detailed case study of real production agent deployment in a safety-critical environment with concrete architectural tradeoffs explained.

**LatentSkill: From In-Context Textual Skills to In-Weight Latent Skills for LLM Agents** — https://huggingface.co/papers/2606.06087
Shows that skill knowledge can be internalized into model weights rather than kept as in-context text, outperforming in-context skill baselines while dramatically reducing prefill token costs.
*Why it matters for practitioners:* Baking skills into weights at fine-tuning time means agents can handle more tasks per context window — this directly affects context cost and latency in production agent pipelines where prompt budgets are tight.

## Blog Posts & Articles

**"Don't classify. Hallucinate!"** — https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/
Simon Willison covering Doug Turnbull's technique: let an LLM freely generate tags without seeing your taxonomy, then resolve those hallucinated tags to real ones via vector similarity search against the existing vocabulary.
*Why it matters for practitioners:* This pattern decouples LLM classification from schema shipping — cheaper models can handle the generation step, and you never need to cram a large vocabulary into every prompt, cutting both token cost and prompt complexity at scale.

**"How Much Memory Does Your Agent Actually Need?"** — https://huggingface.co/blog/ibm-research/altk-evolve-hmm
IBM Research study measuring actual memory consumption across production agent workloads, comparing semantic, episodic, and working memory patterns under real task distributions.
*Why it matters for practitioners:* Most agent memory designs are intuition-driven; empirical data on which memory types get actually accessed under real workloads gives a rational basis for deciding what to build and at what cost.

**"Record, Train, and Deploy from One Place with Strands Agents, LeRobot, and Hugging Face Storage Buckets"** — https://huggingface.co/blog/amazon/strands-lerobot-streaming-data-loop
Amazon and Hugging Face demonstrating a complete data-collection → training → deployment loop for embodied agents using AWS Strands, LeRobot, and HF Storage as a unified pipeline.
*Why it matters for practitioners:* End-to-end pipelines for agent training have been fragmented across frameworks — this integration shows what a production-ready continuous learning loop looks like, with architecture patterns transferable to non-robot agentic pipelines.

**"Stop Making TUIs"** — https://simonwillison.net/2026/Aug/21/stop-making-tuis/
Simon Willison and Thomas Ptacek argue that coding agents have reduced the cost of building native GUIs to near-zero, so there is no longer a practical reason to stop at a terminal UI for internal tools.
*Why it matters for practitioners:* The cost model of interface development has shifted — the implicit barrier that kept internal AI tools as CLIs no longer holds, and teams shipping agent-powered tools should revisit their default interface choices.

**"Lessons from the Hacks"** — https://www.interconnects.ai/p/lessons-from-the-hacks
Nathan Lambert analyzing documented cyberattacks involving frontier AI models and diagnosing the incentive mismatch between competitive AI deployment timelines and the pace of societal response.
*Why it matters for practitioners:* Understanding how current deployment incentive structures interact with emerging threat vectors matters for teams deciding how quickly to ship agentic systems with external network access and real-world permissions.
