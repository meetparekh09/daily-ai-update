## Trending Papers

**What is Missing from AI Post-Training AI: An Empirical Analysis** — https://arxiv.org/abs/2608.19072
A study of LLM agents automating the post-training pipeline end-to-end (writing code, launching runs, evaluating checkpoints) that finds they lock in a training strategy at the start and never revise it — they iterate locally but never update their high-level plan as evidence accumulates; an experience-driven scaffold fixes execution-level failures, yielding +12.6 pts on GSM8K and +40.8 on HumanEval.
*Why it matters for practitioners:* If you're building agentic research or auto-ML pipelines, this is the clearest empirical account of the current ceiling — agents can execute a strategy but can't yet reason about whether to abandon it; the failure mode to design around is strategy lock-in, not just local errors.

**Recurrent Latent Reasoning at 150M Parameters (Pathway)** — https://huggingface.co/papers/trending
A 150M-parameter reasoning model from Pathway that uses recurrent latent computation (looped inference passes over hidden activations) to achieve a new cost-accuracy frontier on ARC-AGI-1, garnering 770 upvotes on Hugging Face Papers in August 2026.
*Why it matters for practitioners:* This is the same looped-transformer architecture OpenAI is reportedly using in Astra — the paper demonstrates it's viable at a very small parameter count, which has direct implications for edge inference and the cost of running capable reasoning models in production.

**INFRAMIND: Infrastructure-Aware Multi-Agent Orchestration** — https://arxiv.org/abs/2606.11440
An orchestration framework that makes the runtime state of the serving infrastructure (queue depths, load, latency) a first-class input at every layer — planner, executor, and scheduler — rather than treating model selection and topology as a static decision; delivers up to +7.6 pp accuracy over the strongest baseline at low load, 7× lower latency, and 99.9% SLO compliance under high load where every baseline drops below 50%.
*Why it matters for practitioners:* If you run multi-agent pipelines on shared GPU clusters, infrastructure blindness is a real source of latency and SLO failures that clever routing cannot fix — this gives a concrete design for making infrastructure state observable to the orchestrator.

**StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction** — https://arxiv.org/abs/2605.06642
Introduces an explicit trajectory-level strategy into agentic RL: StraTA samples a compact strategy from the initial task state, conditions all subsequent actions on that strategy, and trains strategy generation and action execution jointly with a hierarchical GRPO-style rollout design; consistently improves both sample efficiency and final performance over strong baselines on ALFWorld, WebShop, and SciWorld.
*Why it matters for practitioners:* Purely reactive RL agents struggle on long-horizon tasks because credit assignment degrades across many steps; StraTA's hierarchical design separates "choose a plan" from "execute an action" — a pattern with direct applicability to tool-calling and multi-step task agents.

**FreeToken: Edge-Native Mixture-of-Experts Serving (UC Berkeley)** — https://huggingface.co/papers/trending
A serving system from UC Berkeley that dynamically maps MoE computation and model state onto heterogeneous personal hardware (mixed CPUs, GPUs, memory) to run large open-weight models on local machines without cloud infrastructure; received 107 upvotes on Hugging Face Papers.
*Why it matters for practitioners:* As open-weight MoE models proliferate, the constraint shifts from model availability to serving cost; FreeToken's approach to heterogeneous scheduling is a template for anyone building local or edge deployments of models like Mixtral or Qwen-MoE.
