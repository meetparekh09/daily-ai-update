## Trending Papers

**Agentic Data Engineering for LLMs: System Design and a Controlled Empirical Study** — https://arxiv.org/abs/2610.14238
Introduces a framework (ADE) in which agents autonomously pursue, revise, and combine LLM training strategies—covering data selection, reward design, and curriculum learning—with cumulative feedback, reporting up to 13.34% improvement on AIME25 Pass@32 over generic baselines (NeurIPS 2026).
*Why it matters for practitioners:* The first controlled evidence that an AI-in-the-loop system can find training strategies that generalize to held-out benchmarks, suggesting agentic automation of the ML experimentation loop is closer to production-ready than assumed.

**MEMENTO: Learning Context Management for Long Context Processing Agents** — https://arxiv.org/abs/2611.00244
Trains an 8B-parameter agent (Qwen3) via RL to self-manage its context by compacting history into structured notes, achieving 67.8% accuracy (up from 36.9%) on book-level QA spanning 2.5M tokens while never holding more than 20K tokens in context.
*Why it matters for practitioners:* Demonstrates that context management can be learned end-to-end—not just engineered at the harness level—which changes the tradeoff calculus between long-context inference cost and agent quality.

**Skill Transfer: Adapting Agent Skills from Strong to Weak Agents** — https://arxiv.org/list/cs.AI/new
Studies how agent skills authored on frontier models can be adapted to smaller, weaker models without rewriting from scratch, targeting the common production scenario where budget forces a switch from GPT-5-class to 7B-class inference.
*Why it matters for practitioners:* If skills are truly transferable, teams can iterate on agent capabilities with expensive frontier models and then distill to cheaper ones—a significant reduction in the cost of building production agent systems.

**Can Large Language Model Agents Learn by Watching Tutorial Videos?** — https://arxiv.org/abs/2611.01460
Introduces VidLearn, a benchmark testing whether multimodal agents can acquire new procedural skills from instructional videos without any weight updates, reporting relative accuracy gains over vanilla multimodal models.
*Why it matters for practitioners:* Opens the question of whether video-based skill transfer is a viable alternative to tool documentation or code examples, with implications for how agent skill libraries are built and maintained.

**Distilling Agentic Systems: A Roadmap across Models, Artifacts, and Harnesses** — https://arxiv.org/abs/2609.36630
Lays out a systematic taxonomy for distilling agentic systems, distinguishing what can be transferred at the model level, the artifact level, and the harness level.
*Why it matters for practitioners:* Provides a shared vocabulary and decision framework for teams deciding where to invest distillation effort—underserved as a topic given how often teams rebuild the same transfer pipeline from scratch.
