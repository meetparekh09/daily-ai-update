## Trending Papers

**Osprey: Production-Ready Agentic AI for Safety-Critical Control Systems** — https://arxiv.org/abs/2508.15066
A framework deployed at Lawrence Berkeley National Laboratory's Advanced Light Source that operates tens of thousands of accelerator control channels via a plan-first orchestrator (generates full execution plans for human review before hardware is touched) plus a dynamic tool classifier that keeps prompts compact as facilities scale.
*Why it matters for practitioners:* This is a rare production post-mortem with concrete architectural decisions explained — the plan-before-act pattern and tool-scope reduction are directly applicable to any agent system where mistakes are expensive or irreversible.

**AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses** — https://arxiv.org/abs/2608.12307
A study showing that a stronger "builder" model can construct inference-time harnesses that help a weaker "target" model solve Theory-of-Mind benchmarks more reliably, with no parameter updates to the target — iteratively refining the harness over multiple rounds using 5% of validation data.
*Why it matters for practitioners:* If harnesses can transfer capability without fine-tuning, this is a new lever for teams that need to run cheaper models in production: build the harness once with your frontier model, deploy with your smaller model.

**OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution** — https://arxiv.org/abs/2608.00677
An open-ended arena with 10,000+ validated stateful scenarios across 50 domains, drawing from 500,000+ tools and skills, that uses Evolutionary Markov Hypergraph Attack (EMHA) to systematically explore how cumulative state changes across long-horizon tasks create attack surfaces that static benchmarks miss.
*Why it matters for practitioners:* The median task in OpenART requires 97 tool calls — the finding that cumulative-state attacks only surface over long horizons means most teams are stress-testing their agents against the wrong threat model.

**Stealing Reasoning Traces from Proprietary LLM APIs** — https://arxiv.org/abs/2608.09867
A paper (covered by Simon Willison on Aug 11) revealing that encrypted chain-of-thought blocks from Anthropic, OpenAI, and Google are replay-compatible across sessions, users, and models — enabling a decryption jailbreak where a trace from a well-guarded model is injected into a weaker model to force plaintext output.
*Why it matters for practitioners:* If you're building systems where reasoning traces pass between services or are stored — for caching, auditing, or context reuse — this is a live threat to your security model that requires architectural review, not just prompt hardening.

**Spark-to-Paper: End-to-End Research Paper Generation as a Composable Skill** — https://arxiv.org/abs/2608.11924
A 13-skill system built inside an existing coding assistant that takes a research spark to a publication-ready manuscript — retrieving literature, running experiments, revising claims against evidence, and producing figures — at 99.5% citation validity, $8.1 per manuscript, in 3.2 hours.
*Why it matters for practitioners:* The integrity stack (adversarial review raises fabrication detection from 14% to 92%) and the Self-Refutation Loop handler (preserves failed trajectories as reports) are reusable patterns for any long-horizon agentic pipeline where output correctness is load-bearing.
