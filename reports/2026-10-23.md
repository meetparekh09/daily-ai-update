## Trending GitHub Repositories

**sickn33/agentic-awesome-skills** — [github.com/sickn33/agentic-awesome-skills](https://github.com/sickn33/agentic-awesome-skills)
A curated catalog of 2,715+ installable SKILL.md playbooks for LLM agents, spanning coding, research, data, and domain-specific tasks.
*Why it matters for practitioners:* Standardized, composable skill definitions signal a shift toward treating agent behaviors as packages you install rather than prompts you write from scratch — worth watching as a potential de-facto registry.

**Mem0** — [github.com/mem0ai/mem0](https://github.com/mem0ai/mem0)
A persistent memory layer for AI agents (67K+ stars) that stores, retrieves, and updates user- and context-specific memories across sessions.
*Why it matters for practitioners:* Long-lived agents need durable memory that survives context resets; Mem0 is one of the few projects solving this at infrastructure level rather than prompt engineering.

**RAGFlow** — [github.com/infiniflow/ragflow](https://github.com/infiniflow/ragflow)

*Why it matters for practitioners:* Consolidating the full RAG pipeline into a tested system reduces integration surface; worth benchmarking against hand-assembled pipelines before building your own.

**Graphify-Labs/graphify** — [github.com/Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)

**vllm-project/vllm** — [github.com/vllm-project/vllm](https://github.com/vllm-project/vllm)

## Trending Papers

**"Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought"** — [arxiv.org/abs/2610.30755](https://arxiv.org/abs/2610.30755)
A benchmark (LoCoMo, LongMemEval, MEME, MemoryAgentBench) comparing a plain RAG baseline against six complex agent memory systems, with the naive baseline ranking first.
*Why it matters for practitioners:* Before investing in sophisticated memory architectures, the field now has direct evidence to establish a naive RAG ceiling — teams should benchmark against it first.

**"Projected Distillation: On Learning to Solve Hard Problems from Close, Correct Targets"** — [arxiv.org/abs/2610.27467](https://arxiv.org/abs/2610.27467)
Addresses the failure mode in on-policy distillation where early-trajectory mistakes cascade into useless supervision, proposing a corrected-prefix projection approach for bootstrapping on tasks where RL returns no reward.
*Why it matters for practitioners:* Directly answers the cold-start problem in agent training on hard tasks — where RL fails because all rollouts fail — offering a path to supervised signal where none existed.

**"Memory Type Varies: Empowering LLM Agents for Long-Term Memory with Diverse Strategies"** — [arxiv.org/abs/2610.11573](https://arxiv.org/abs/2610.11573)
NeurIPS 2026 accepted paper proposing query-routing across multiple retrieval strategies by memory type, reporting a 16.18% improvement in Recall@1 over uniform retrieval.
*Why it matters for practitioners:* NeurIPS-validated evidence that one retrieval strategy does not fit all memory types; routing by memory type is a concrete, implementable improvement.

**"RAISED: Self-Distillation for Robustness to Prompt Injection in LLM Agents"** — [arxiv.org/abs/2610.06401](https://arxiv.org/abs/2610.06401)
A self-distillation defense that substantially reduces indirect prompt injection success rates in tool-using agents while preserving task utility on agentic benchmarks.
*Why it matters for practitioners:* Security through distillation generalizes to unseen injection patterns in ways that static filters do not — the first approach that makes the agent itself adversarially aware.

**"More Methods, Better Agents? A Reality Check on Self-Distillation in Agentic Settings"** — [arxiv.org/abs/2610.19789](https://arxiv.org/abs/2610.19789)
A systematic benchmark of self-distillation methods for agent training, arguing for reproducible comparison baselines since reproducing agent training is expensive.
*Why it matters for practitioners:* Calls out that many agent-distillation claims lack apples-to-apples comparison; the shared benchmark it proposes is the right lens for evaluating new training recipes.
