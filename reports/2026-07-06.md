## Trending Papers

**ADWIN: Adaptive Windows for Horizon-Aware On-Policy Distillation** — https://arxiv.org/abs/2605.28396
Treats rollout length in on-policy distillation (OPD) as an online admissibility decision—training on short teacher-anchored prefixes and asynchronously auditing prefix-full alignment—reducing end-to-end training cost by up to 4.1× while maintaining comparable or better accuracy on math and code benchmarks.
*Why it matters for practitioners:* On-policy distillation is currently one of the most effective post-training paradigms for reasoning models, but its cost is prohibitive at scale; ADWIN is a concrete handle for teams running OPD who need to reduce compute without sacrificing quality.

**OpenClaw-RL: Train Any Agent Simply by Talking** — https://arxiv.org/abs/2603.10165
A unified RL framework (Princeton, March 2026) that recovers next-state signals—user replies, tool outputs, terminal/GUI state changes—from live agent interactions as an online training source, enabling agents to improve continuously simply by being used in production.
*Why it matters for practitioners:* Closes the feedback loop between deployment and training: instead of periodic offline retraining, every production interaction becomes a learning signal, fundamentally changing how you think about the improvement cycle for deployed agents.

**The Finetuner's Fallacy: When to Pretrain with Your Finetuning Data** — https://arxiv.org/abs/2603.16177
Challenges the default assumption that target-domain data should only be used at SFT time, demonstrating systematic conditions under which folding that data into pretraining yields meaningfully better outcomes than staging it as a fine-tuning phase.
*Why it matters for practitioners:* Provides a principled answer to a question most teams resolve by folklore—whether to run a domain-adapted pretraining stage or jump straight to SFT—and surfaces cases where the common default is leaving performance on the table.

**DeepSieve: Information Sieving via LLM-as-a-Knowledge-Router** — https://arxiv.org/abs/2507.22050
An agentic RAG system (EACL 2026, NEC Labs) that decomposes complex queries into structured sub-questions, routes each to the most suitable knowledge source via thought generation, and refines answers through recursive reflexion over heterogeneous sources.
*Why it matters for practitioners:* Offers a concrete alternative to flat RAG retrieval for multi-hop queries: the decompose-route-reflect loop measurably improves retrieval precision and answer quality on knowledge-intensive tasks, and the components are modular enough to retrofit onto existing pipelines.

**A-RAG: Scaling Agentic Retrieval-Augmented Generation** — https://arxiv.org/abs/2602.03442
Exposes three hierarchical retrieval tools—keyword_search, semantic_search, and chunk_read—directly to the LLM, enabling the model to adaptively plan its own multi-granularity retrieval strategy rather than relying on a fixed pipeline with pre-determined retrieval depth.
*Why it matters for practitioners:* By giving the model direct control over retrieval granularity, A-RAG aligns retrieval effort with the model's actual information need—a tractable architectural change to existing RAG systems with demonstrated accuracy improvements on multi-hop tasks.
