## Trending Papers

**RAISED: Self-Distillation for Robustness to Prompt Injection in LLM Agents** — https://arxiv.org/abs/2610.06401
Uses self-distillation at training time to make tool-using LLM agents significantly more resistant to indirect prompt injection attacks, without the usual tradeoff of degraded performance on legitimate agent tasks.
*Why it matters for practitioners:* Prompt injection is the most realistic attack vector on deployed agents — this is the first technique that credibly improves robustness without hurting utility, making it directly applicable to any agent exposed to untrusted tool output.

**MemPilot: On-Demand Multimodal Memory Curation for LLM Agents** — https://huggingface.co/papers (search: MemPilot 2026)
Proposes a system that curates agent memory on demand across text, image, and structured data, deciding what to store, compress, and surface at each step of a multi-turn agent run.
*Why it matters for practitioners:* Most persistent-memory systems treat memory as a retrieval problem; MemPilot treats it as a curation problem — the distinction matters for agents handling heterogeneous context across long sessions.

**AgentGarten: Code Worlds for Evolving Agents** — https://huggingface.co/papers (search: AgentGarten 2026)
Argues that agents should be trained through continuous interaction with richly structured code environments (not static datasets), showing that environment diversity and reward signal from execution outperform supervised fine-tuning on agent benchmarks.
*Why it matters for practitioners:* If execution-based learning in code environments generalizes, it reframes the question of how to improve agents — the training environment design becomes as important as the model architecture.

**Orthros: Phase-Aware Attention for Efficient Transformers** — https://arxiv.org/abs/2610.13735
A NeurIPS 2026 submission introducing phase-aware attention that reduces memory and compute costs in transformers by aligning attention patterns with distinct processing phases (encoding vs. reasoning vs. generation).
*Why it matters for practitioners:* Attention efficiency gains that don't require architectural overhaul — if adopted in inference engines, this reduces the cost of running reasoning-heavy agent loops at scale.

**Distilling Agentic Systems: A Roadmap across Models, Artifacts, and Harnesses** — https://arxiv.org/abs/2609.36630
A structured survey and research agenda covering on-policy distillation, artifact-level distillation, and harness-level compression for agentic systems, synthesizing a year of rapid work in the area.
*Why it matters for practitioners:* Rather than tracking 20 individual distillation papers, this gives a framework for deciding which distillation technique fits your agent architecture — models, traces, or the surrounding harness — and what the open problems are.
