## Trending Papers

**CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling** — https://arxiv.org/abs/2610.06829
A framework (October 2026) that trains web agents to verify their own browser rollouts using conformal prediction as a certifier, replacing costly external judge models; sets state-of-the-art among open-source web agents on WebArena Infinity.
*Why it matters for practitioners:* Self-verification via conformal certification is a principled alternative to expensive reward models or human labelers—if it transfers broadly, it substantially lowers the cost of training and evaluating web/browser agents.

**Training Long-Context, Multi-Turn Software Engineering Agents with Reinforcement Learning** — https://arxiv.org/abs/2508.03501
Uses a modified DAPO algorithm to train an agent on real software engineering tasks, lifting SWE-bench Verified performance from a 20% rejection-sampled baseline to 39%—with no teacher model distillation.
*Why it matters for practitioners:* A 2× lift on SWE-bench using pure RL (no teacher) tells practitioners that online RL on real task distributions is now a viable and powerful post-training path, not just a theoretical curiosity.

**Clean: Second-Order LLM Training at Linear Memory Cost via Nyström Sketching** — https://arxiv.org/list/cs.LG/current
Achieves second-order (curvature-aware) optimization for LLM training while keeping memory cost linear in parameter count by approximating the Hessian with Nyström sketches.
*Why it matters for practitioners:* Second-order methods converge faster but were memory-prohibitive for large models; if this holds up at scale, it changes the compute-versus-step-count tradeoff for anyone training or fine-tuning models from scratch.

**T2SPO: Trajectory-to-Step Policy Optimization for Agentic Reinforcement Learning** — https://arxiv.org/list/cs.LG/current
Introduces a policy optimization method that decomposes trajectory-level rewards into per-step credit signals, addressing the credit assignment problem in long-horizon agentic RL.
*Why it matters for practitioners:* Sparse trajectory-level rewards are a core bottleneck in training RL agents for long tasks; a principled step-level decomposition makes it feasible to train agents on tasks with hundreds of actions before getting feedback.

**Scaling Agentic Data for Long-Horizon Terminal Intelligence** — https://huggingface.co/papers
Proposes a data collection and curation strategy for scaling training data for long-horizon terminal (shell/CLI) agents; appeared in the Hugging Face daily papers feed this week.
*Why it matters for practitioners:* Data quality and diversity at the agentic level (multi-step trajectories rather than prompt-response pairs) is the underexplored bottleneck in training capable agents—this paper directly addresses the "how do you get enough on-policy data" question.
