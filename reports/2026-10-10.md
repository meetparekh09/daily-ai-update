## Trending Papers

**WEFT: Scaling Tool-Use Post-Training for General-Purpose Agents** — [huggingface.co/papers](https://huggingface.co/papers)
A post-training method that fine-tunes foundation models to reliably orchestrate large, heterogeneous tool libraries, scaling to hundreds of tools without performance collapse (top pick in the Oct 7 HuggingFace Daily Papers digest).
*Why it matters for practitioners:* Tool-use reliability is one of the main blockers to deploying general-purpose agents; this is a systematic post-training recipe for it that generalizes across tool types.

**Scaling Trajectories for Complex Tasks through Recursive Self-Rewrite** — [huggingface.co/papers/date/2026-10-05](https://huggingface.co/papers/date/2026-10-05)
Generates SFT training trajectories by having agents recursively rewrite their own failed solutions under different task harnesses, standardizing successful ones into a fine-tuning corpus (~90 HuggingFace upvotes).
*Why it matters for practitioners:* Directly applicable to coding-agent post-training pipelines: turns failure traces into a self-correcting data flywheel, making high-quality trajectory generation significantly cheaper.

**Safety Does Not Compose: Non-Decaying Loop State for Autonomous LLM Agents** — [arxiv.org/abs/2608.27141](https://arxiv.org/abs/2608.27141)
Demonstrates that trajectory-level agent safeguards silently reset their accumulated safety state at each new trajectory start, creating exploitable gaps in long-running or multi-session agentic systems.
*Why it matters for practitioners:* If you assume existing agent guardrails accumulate constraints across trajectories, this paper shows you're wrong—and proposes the architectural change (persistent non-decaying loop state) needed to close the gap.

**SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training** — [arxiv.org/abs/2606.02355](https://arxiv.org/abs/2606.02355)
A training framework that lets LLM agents develop and internalize reusable sub-skills through RL, without requiring hand-designed reward functions for each individual skill.
*Why it matters for practitioners:* Removes a key bottleneck in agent RL training—manual reward engineering—by letting agents self-organize their action space into learnable skill primitives.

**Temporary Authority, Permanent Effects: Commit-Time Authorization for LLM Agents** — [arxiv.org/abs/2607.10487](https://arxiv.org/abs/2607.10487)
Proposes a formal authorization model where a derived state is permitted only while its originating permission remains fresh, causally prior, and effect-bound at the moment the action commits—not just at the moment it was requested.
*Why it matters for practitioners:* Closes the gap between "agent was authorized at request time" and "agent is still authorized when the irreversible effect lands"—a concrete model for anyone building agents with database writes, API calls, or deployment actions.
