## Trending Papers

**Librarian Agents: Training LLMs to Curate Long-Context Workspaces that Anticipate Future Queries** — <https://arxiv.org/abs/2610.22273>
Trains LLMs to proactively organize and compress information in a long-context workspace based on what queries are likely to arrive later, rather than waiting to retrieve on demand.
*Why it matters for practitioners:* This flips the standard RAG framing — instead of reactive retrieval, the agent learns to pre-curate its own working memory; if the approach holds up in ablations, it is a concrete alternative to chunking + embedding pipelines.

**Beyond On-Policy vs. Off-Policy: At What Level Should LLM Agent Distillation Follow the Student?** — <https://arxiv.org/abs/2610.31918>
A systematic study of when teacher demonstrations versus student-generated trajectories should drive agent training, finding that the optimal strategy depends on the task horizon and environment dynamics.
*Why it matters for practitioners:* On-policy distillation is widely assumed to be the safe default; this paper's finding that neither policy dominates consistently updates the decision rule for anyone building agent training pipelines.

**Agent Behavior as Code: Programmatic Specifications for Efficient and Robust LLM Agents** — <https://arxiv.org/abs/2610.04824>
Proposes expressing agent policies as structured code specifications rather than natural-language prompts, enabling static analysis, deterministic testing, and more reliable execution.
*Why it matters for practitioners:* Treating agent behavior as a formal artifact rather than a prompt string directly addresses the brittleness and debuggability problems that plague production deployments.

**Sentry: Learning to Recover from LLM Agent Failures at Test Time** — <https://arxiv.org/abs/2610.02994>
Introduces a test-time recovery mechanism that detects when an agent has entered a failure mode and learns lightweight corrections without retraining the base model.
*Why it matters for practitioners:* Rather than hoping agents don't fail, Sentry treats failure recovery as a first-class runtime concern — the architecture is worth understanding before your next incident.

**RAISED: Self-Distillation for Robustness to Prompt Injection in LLM Agents** — <https://arxiv.org/abs/2610.06401>
Uses self-distillation to train agents that substantially resist prompt injection attacks in tool responses while preserving task utility on standard agentic benchmarks.
*Why it matters for practitioners:* Prompt injection remains the leading attack vector against tool-using agents; a training-time mitigation that doesn't require a separate guard model is operationally simpler and worth benchmarking against your current defenses.
