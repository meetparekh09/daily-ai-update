## Trending Papers

**GraphOPD: Graph-Augmented On-Policy Distillation for LLM Agents** — https://arxiv.org/abs/2610.08959
Submitted October 6; argues that step-selection by teacher-student divergence fails on multi-turn agent tasks and proposes graph-structured step selection instead.
*Why it matters for practitioners:* Challenges a common assumption in on-policy distillation recipes—that high-divergence steps are the most informative—and offers a concrete replacement that holds across long-horizon agentic tasks.

**RRSI: Regularized Recursive Self-Improvement of Agent Harnesses** — https://huggingface.co/papers
Introduces regularization constraints on the evolutionary search over agent harness configurations to prevent overfitting to training task distributions.
*Why it matters for practitioners:* Addresses the brittleness of self-improving agents that hit high benchmark numbers but fail out-of-distribution—a pattern many teams encounter when evaluating agents built with unconstrained RL.

**RL Starts before RL: On-Policy Distillation for Better Reinforcement Learning** — https://arxiv.org/abs/2609.28145
Reframes on-policy distillation as a pre-training phase for RL and proposes measuring distillation choices by post-RL performance rather than imitation loss.
*Why it matters for practitioners:* Changes the mental model of when to stop distillation—not when imitation loss plateaus, but when downstream RL headroom is maximized—a practical recipe change for anyone combining OPD and RLHF.

**OPID: On-Policy Skill Distillation for Agentic Reinforcement Learning** — https://arxiv.org/pdf/2606.26790
Applies on-policy distillation at the skill level rather than the token level, letting agent sub-policies be distilled independently and composed at inference time.
*Why it matters for practitioners:* Modular skill distillation allows partial updates—distilling a new tool-use skill without retraining the entire agent—a significant reduction in iteration cost for production agent systems.

**What Agents Do: Exgentic Agent LLM Traces v2** — https://huggingface.co/blog/michalshmu/exgentic-agent-llm-traces-v2
Releases a dataset of 10K real agent runs (242K model calls) across five models and five agent designs, normalized to a single schema.
*Why it matters for practitioners:* Provides empirical ground truth about how agents actually use tools in the wild—far more useful for fine-tuning than synthetic trajectories and a direct input for evaluation harnesses.
