## Trending Papers

**Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning** — https://arxiv.org/abs/2607.21653
NVIDIA NeMo Labs releases a ~8,600-line PyTorch-native framework for training agent policies with RL, matching Megatron throughput under a fully asynchronous protocol while staying compact enough for a researcher to modify end-to-end.
*Why it matters for practitioners:* Molt's design principle—small enough for one researcher to hold in their head, legible enough for a coding agent to modify—makes it the practical open baseline for agentic RL research; the throughput parity with Megatron means there's no performance reason to use a heavier stack.

**Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills** — https://arxiv.org/abs/2607.22529
Alibaba introduces a reinforcement learning loop where a proposer, solver, and dynamic skill controller co-evolve: each skill grounds verification in a specific domain, while dynamic routing across skills preserves open-ended task variety.
*Why it matters for practitioners:* Cleanly resolves the core tension in self-evolutionary training—diverse tasks vs. reliable verification—without human-curated data; a new template for extending model capability in domains where labeled supervision is scarce.

**DataPrep-Bench: Benchmarking LLMs as Training Data Preparators** — https://arxiv.org/abs/2607.20465
First unified benchmark evaluating LLMs on both data construction (raw sources → supervised training data) and data quality evaluation, across six domains and multiple base models.
*Why it matters for practitioners:* Reveals where LLMs fail when tasked with curating their own training data, and introduces a skill-guided agent that lifts fine-tuning performance ~20 points absolute on Llama-3.1-8B; essential reading for anyone building LLM-driven data pipelines.

**Bayesian Uncertainty Propagation for Agentic RAG Pipelines** — https://arxiv.org/abs/2607.00972
Wraps a multi-hop RAG pipeline (planner → evaluator → generator) with Bayesian networks that propagate uncertainty signals from each stage into an overall system-level confidence estimate and per-node failure indicators.
*Why it matters for practitioners:* Gives agentic RAG systems a principled signal for selective abstention—propagated uncertainty identifies which hop in a multi-step query is most likely to fail before a bad answer reaches the user.

**RAG-MCP: Mitigating Prompt Bloat in LLM Tool Selection via Retrieval-Augmented Generation** — https://arxiv.org/abs/2505.03275
Semantic retrieval pre-selects the relevant MCP tools for each query before the LLM ever sees them, cutting prompt tokens by 50%+ and tripling tool selection accuracy vs. the full-tool-list baseline.
*Why it matters for practitioners:* As MCP tool registries grow to dozens or hundreds of tools, passing all descriptions in context becomes expensive and inaccurate; RAG-for-tool-selection is the practical fix, and this paper is the cleanest demonstration of the pattern.
