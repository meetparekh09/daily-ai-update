## Trending Papers

**SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning** — https://arxiv.org/abs/2607.14777
Introduces a self-evolving framework that converts completed on-policy trajectories into hindsight skills (natural-language reusable workflows) and distills them back into the policy during RL, without a separate teacher model. (July 2026)
*Why it matters for practitioners:* Closing the loop between trajectory analysis and policy update — without needing a larger teacher — is a practical path to continual agent improvement on your own data, and the hindsight skill extraction technique is directly applicable to any agentic RL setup.

**Osprey: Production-Ready Agentic AI for Safety-Critical Control Systems** — https://arxiv.org/abs/2508.15066
Describes a framework deployed at a particle accelerator and a wind farm, featuring a plan-first orchestrator for human review before any hardware contact, a dynamic tool classifier, and connector abstractions for different control systems. (APL Machine Learning 2026)
*Why it matters for practitioners:* The plan-review-before-execution pattern and the dynamic tool classifier (preventing prompt bloat as capabilities grow) are directly portable to any production agent deployment where stakes are high and tool surfaces are large.

**On-Policy Distillation with Curriculum Turn-level Guidance for Multi-turn Agents** — https://arxiv.org/abs/2606.15912
Proposes a curriculum approach to on-policy distillation for multi-turn dialogue agents, progressively increasing the difficulty of the distillation target turn-by-turn to stabilize training. (June 2026)
*Why it matters for practitioners:* Multi-turn agent training is notoriously unstable; curriculum-guided distillation at the turn level is a concrete technique that can be layered onto existing on-policy setups to improve data efficiency and convergence.

**MemGraphRAG: Memory-based Multi-Agent System for Graph Retrieval-Augmented Generation** — https://arxiv.org/abs/2606.00610
Presents a multi-agent system where a memory module backed by a graph structure routes retrieval across agents depending on query type, accepted at KDD 2026. (June 2026)
*Why it matters for practitioners:* Graph-structured memory addresses the flat-retrieval failure mode in complex multi-hop queries; the multi-agent routing layer is a clean pattern for anyone extending RAG systems toward deeper reasoning chains.

**A Comprehensive Survey of Self-Evolving AI Agents** — https://arxiv.org/abs/2508.07407
A 15-author survey that abstracts the feedback loop underlying self-evolving agentic systems — covering experience collection, skill extraction, and policy update — and taxonomizes existing approaches against that framework.
*Why it matters for practitioners:* Provides a unified vocabulary and design checklist for building agents that improve themselves from deployment data, which is increasingly the expected baseline for production-grade agent systems.
