## Trending Papers

**Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading** — https://arxiv.org/abs/2607.08964
A benchmark of 46 long-horizon terminal tasks across 9 categories (experiment reproduction, software engineering, multimodal analysis, scientific computing, and more) where the best-tested model achieves only 15.2% at partial-credit and 10.9% at perfect-score thresholds, with a mean pass rate of 4.3% across all models.
*Why it matters for practitioners:* The 4–10% baseline shatters optimistic assumptions about what current coding agents can actually accomplish end-to-end in realistic settings — dense intermediate rewards expose where agents collapse long before task completion, which is critical input for anyone designing long-horizon agent evals or setting customer expectations.

**DeepSearch-World: Self-Distillation for Deep Search Agents in a Verifiable Environment** — https://arxiv.org/abs/2607.07820
A framework that trains search agents via self-distillation in a controlled, verifiable environment where the agent generates its own training signal by comparing its search trajectories against ground-truth outcomes — published July 3, 2026.
*Why it matters for practitioners:* Self-distillation in a verifiable env avoids the need for expensive human-labeled search trajectories; if this generalizes, it is a scalable path to training capable search agents using only the environment's reward signal — a direct method update for teams building RAG or agentic retrieval systems.

**Learning User-Aware Recall: Personalized Retrieval in Long-Term Conversational Memory** — https://arxiv.org/abs/2607.00017
Introduces PPRO (Profile-guided Personalized Retrieval Optimization), a retrieval-centric framework that makes memory retrieval user-conditioned and differentiably optimizable, rather than relying on fixed query-similarity ranking rules, from researchers at Baidu and U. Queensland.
*Why it matters for practitioners:* Most RAG and agent memory systems today use query-centered similarity; PPRO shows how to inject user context into the retrieval decision itself — a concrete upgrade path for anyone building long-term conversational agents where the same question should surface different memories for different users.

**AgentArk: Distilling Multi-Agent Intelligence into a Single LLM Agent** — https://arxiv.org/abs/2602.03955
Proposes a framework to distill the dynamics of a multi-agent system — the coordination patterns, specialization, and role-switching between agents — directly into the weights of a single LLM, transforming explicit test-time orchestration into implicit model capability.
*Why it matters for practitioners:* Multi-agent systems are expensive and fragile at inference time; AgentArk suggests a training-time path to capturing multi-agent behavior in one model, which could dramatically cut serving costs for teams currently routing between multiple specialized agents.

**Memex(RL): Scaling Long-Horizon LLM Agents via Indexed Experience Memory** — https://arxiv.org/abs/2603.04257
Proposes an indexed experience memory architecture that lets LLM agents accumulate and retrieve past trajectories during RL training, enabling them to reuse successful strategies across long-horizon tasks without relearning from scratch.
*Why it matters for practitioners:* Experience replay is standard in tabular and model-based RL but underexplored for LLM agents; Memex(RL) connects that literature to the agent harness layer, which is a direct extension to anyone using SkyRL, veRL, or similar RL post-training frameworks.
