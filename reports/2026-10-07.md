## Trending Papers

**UNREAL: Unifying Retrieval and Long-Context with a Single Model** — https://arxiv.org/abs/2610.08463
Adds fewer than 500K trainable parameters to a frozen LLM so it can both retrieve relevant documents and handle long-context inference as a single unified operation, with major recall gains on HotpotQA (49→73%) and near-zero degradation on generation tasks.
*Why it matters for practitioners:* The insight that retrieval and long-context attention are the same operation at different scales means you may not need separate retrieval systems — this could substantially simplify RAG architecture.

**Context Language Models** — https://arxiv.org/abs/2609.37725
Proposes CLMs: LMs that natively manage their own context as a file they can append or freely edit via Bash, with a Suffix Cache Reuse (SCR) mechanism that reuses cached KV states beyond the matching prefix to cut re-prefilling costs.
*Why it matters for practitioners:* Natively self-editing context changes the mental model for long-horizon agents — the model is no longer a passive consumer of context but an active manager of its own working memory.

**NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness** — https://arxiv.org/abs/2609.08183
Post-trains a 9B Qwen model using a routing harness that pools heterogeneous models, records trajectories, and applies curriculum distillation to improve performance across agent benchmarks, targeting recursive self-improvement.
*Why it matters for practitioners:* The routing harness approach — using a fleet of heterogeneous models to generate training signal for a single target model — is a practically tractable on-policy distillation recipe that doesn't require access to a frontier model's weights.

**SE-GoS: Self-Evolving Graph-of-Skills for Skill Library at Scale** — https://huggingface.co/papers
Builds a scalable, self-updating graph of reusable skills for LLM agents, enabling agents to discover, compose, and prune skills without manual curation as task distributions shift.
*Why it matters for practitioners:* Static skill libraries rot quickly as agent task distributions change — a self-evolving graph that maintains itself is a more durable pattern for production deployments.

**Pivot-SD: Efficient Self-Distillation for Masked Diffusion Language Models** — https://huggingface.co/papers
EMNLP 2026 Oral: proposes a self-distillation method for masked diffusion LMs that preserves generation quality while significantly reducing inference steps, without requiring a separate teacher model.
*Why it matters for practitioners:* Masked diffusion LMs are an increasingly competitive alternative to autoregressive generation — a training-time efficiency improvement that removes the need for a separate teacher lowers the barrier to training your own.
