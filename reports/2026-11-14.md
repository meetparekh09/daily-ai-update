## Trending Papers

**CoworkOS: A General-Purpose Harness for Long-Horizon Agent Work** — https://arxiv.org/abs/2611.03178
Proposes a three-layer architecture separating task strategy, execution management, and tool interfaces, adding persistent memory and hierarchical workspaces, evaluated across 12 benchmarks and 6 real-world application categories including code, documents, and CAD models.
*Why it matters for practitioners:* The clean strategy/execution separation directly addresses the most common production failure mode in long-horizon agents—where ad-hoc coupling of planning and tool calls makes debugging and iteration prohibitively expensive at scale.

**MLExpert: Towards a Generalist Agentic Model for Autonomous Machine Learning Engineering** — https://arxiv.org/abs/2610.22344
Post-trains a 35B Mixture-of-Experts model for autonomous ML engineering using hierarchical agentic SFT combined with Windowed Interaction RL (WIRL)—which treats multi-turn decisions between successive experiment outcomes as a shared reward window—reaching 72.7% medal rate on MLE-Bench Lite.
*Why it matters for practitioners:* WIRL's milestone-reward framing for multi-turn decisions is a training technique applicable to any domain where long-horizon agent performance is evaluated at outcome checkpoints, not just ML engineering.

**Harness-S: Cross-Harness Behavior Transfer for LLM Agents** — https://arxiv.org/abs/2611.04277
Introduces a method for transferring behaviors from sibling harnesses into a shared policy that generalizes to unseen external harnesses without further fine-tuning, with improvements transferring across different execution interfaces.
*Why it matters for practitioners:* If harness behaviors are truly portable, it means agent capabilities developed on one scaffold can compose with others—a path toward reusable agent skill modules rather than rebuilding capabilities from scratch per deployment.

**TurnOPD: Turn-Level Budgeting for On-Policy Distillation of Long-Horizon Agents** — https://arxiv.org/abs/2607.05804
Proposes a turn-level budgeting strategy that assigns more training signal to deeper decision turns in long-horizon distillation, correcting the supervision depth bias where shallow turns dominate the training loss in standard on-policy distillation.
*Why it matters for practitioners:* Standard trajectory distillation over-trains on the easy early turns and under-trains on the deep reasoning steps where agents actually fail; this targeted fix directly improves sample efficiency for anyone building training pipelines over long-horizon trajectory data.

**ATOD: Adaptive Hybrid Distillation and Reinforcement Learning for Long-Horizon Agents** — https://arxiv.org/abs/2606.27814
Combines on-policy distillation and RL using turn-level disagreement-uncertainty reweighting that dynamically concentrates training signal on the turns where the teacher and student diverge most.
*Why it matters for practitioners:* Pure RL is sample-inefficient on long horizons; pure distillation is brittle under distribution shift; ATOD's hybrid approach with uncertainty-based weighting offers a practical path practitioners can adopt without committing to either paradigm alone.
