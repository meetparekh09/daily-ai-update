## Trending Papers

**Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments** — https://arxiv.org/abs/2609.04148
Replays tool-execution history in existing agent trajectories to reconstruct the original file-system state, yielding 37.3k task-sufficient environments from public data; SFT on this corpus improves Qwen3.5-27B by +11.9 pts on Terminal-Bench 2.1 and +13.8 pts on multi-round EvoCode-Bench.
*Why it matters for practitioners:* It sidesteps the hardest part of agent post-training — building verifiable environments from scratch — by mining them from trajectories already sitting in public repos, making large-scale agent fine-tuning dramatically more accessible.

**LatentPress: Context Compression Beyond Text and Vision** — https://huggingface.co/papers/2609.01507
Compresses conversation history and long documents into continuous memory tokens that a frozen decoder reads directly, achieving 4–16× compression with only a small reader-matched adapter (~4–26M parameters, ~0.1% of the decoder).
*Why it matters for practitioners:* A 4–16× reduction in effective context cost — with no text reconstruction at inference — translates directly to lower latency and cost for long-context agent sessions without retraining the base model.

**KC-Bench: A Dynamic Interactive Benchmark for Evaluating Knowledge Conflicts in LLM Agents** — https://arxiv.org/abs/2609.03588
238 manually screened multi-turn tasks probing how agents reconcile user instructions, parametric knowledge, and live tool observations when they contradict each other across world-knowledge, input inconsistency, and temporal conflict dimensions.
*Why it matters for practitioners:* Knowledge conflicts are a known production failure mode (stale parametric knowledge vs. live retrieval), and this benchmark makes it possible to measure — and therefore improve — agent robustness to them systematically.

**ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration** — https://arxiv.org/abs/2605.03042
An open-source research harness that pairs an executor (Claude) with a reviewer from a different model family (GPT) to catch correlated reasoning errors that single-model self-refinement consistently misses, applied to long-horizon ML research workflows.
*Why it matters for practitioners:* The cross-model adversarial pattern is a concrete architectural recommendation for any pipeline where correctness is critical — using a second-family model as reviewer is cheap insurance against blind spots baked into a single model's training.

**Agent² RL-Bench: Can LLM Agents Engineer Agentic RL Post-Training?** — https://arxiv.org/abs/2604.10547
A six-task benchmark spanning static rule-based training through closed-loop online RL that tests whether LLM agents can autonomously design, implement, and run complete RL pipelines starting from an isolated workspace with a base model, task data, and a grading API.
*Why it matters for practitioners:* If agents can reliably run their own post-training, the iteration loop for specialization compresses dramatically — this benchmark establishes where that frontier currently sits and what structural requirements block it.
