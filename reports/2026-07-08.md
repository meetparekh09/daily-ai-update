## Trending Papers

**Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent (Agents-A1)** — https://arxiv.org/abs/2606.30616
Shanghai AI Lab's 35B MoE model matches GPT-5.5 and DeepSeek-V4-pro by training on long-horizon agentic trajectories averaging 45K tokens rather than scaling parameter count.
*Why it matters for practitioners:* If agent horizon is as powerful a lever as model scale, the economics of frontier agent performance shift dramatically toward trajectory data curation over raw compute budget.

**How to Allocate Your Tokens? Scaling Laws with Training Steps and Batch Size** — https://arxiv.org/abs/2607.01487
Extends Chinchilla with a three-term scaling law modeling loss as a function of parameters, steps, and batch size independently — showing current recipes over-allocate to large batches at the expense of more gradient steps.
*Why it matters for practitioners:* Directly actionable: reallocating compute budget toward more steps for fixed batch size should improve loss, challenging the standard tokens = steps × batch simplification.

**Your Agent's Memories Are Not Its Own: Forged Reasoning Attacks on LLM Agent Memory and Defenses (FARMA)** — https://arxiv.org/abs/2607.05029
Introduces FARMA, an attack that poisons an agent's persisted reasoning chains rather than factual knowledge, causing the agent to apply flawed logic persistently to future situations.
*Why it matters for practitioners:* Any production agent system that stores reasoning traces in memory is vulnerable to a new attack class that bypasses factual-knowledge defenses and compounds over time.

**CARL: Constraint-Aware Reinforcement Learning for Planning with LLMs** — https://arxiv.org/abs/2607.04854
Introduces a constraint-aware reward signal during RL fine-tuning so LLM planning agents learn to respect task constraints (ordering, resource limits, preconditions) without sacrificing task completion rate.
*Why it matters for practitioners:* Constraint violation is among the most common failure modes in deployed LLM planners; this offers a principled training-time fix that doesn't rely on post-hoc output filtering.

**IsoSci: A Benchmark of Isomorphic Cross-Domain Science Problems for Evaluating Reasoning versus Knowledge Retrieval in LLMs** — https://arxiv.org/abs/2607.01431
Pairs science problems with identical logical structure but different domain knowledge, revealing that LLMs scoring well on standard benchmarks often fail the isomorphic version — indicating pattern-matching over genuine reasoning.
*Why it matters for practitioners:* Teams evaluating LLMs for reasoning-heavy tasks need structurally novel test cases; held-out examples from familiar domains systematically overestimate reasoning ability.
