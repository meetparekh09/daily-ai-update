## Trending Papers

**LLMZero: Discovering Adaptive Training Strategies for RL Post-Training via LLM Agents** — <https://arxiv.org/abs/2606.18388>
Uses LLM agents to search over the space of RL training configurations via tree search, finding strategies that improve over baseline by 9–140% relative and over grid search by 6–15%.
*Why it matters for practitioners:* This flips the usual human-designs-training-recipe assumption: the optimizer is itself an LLM agent, opening a path to self-improving training pipelines that adapt strategy to each model and task.

**Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents** — <https://arxiv.org/abs/2606.26080>
Identifies annotation-free "progress advantage" signals that emerge as a natural byproduct of RL post-training, validated across test-time scaling, uncertainty quantification, and failure attribution.
*Why it matters for practitioners:* These signals are already sitting in your RL training logs for free—using them improves agent performance without any labeling overhead, which changes the cost calculus on iterative post-training.

**A Few Teacher Steps Go a Long Way: Cost-Efficient On-Policy Data Augmentation for Agent Post-Training** — <https://arxiv.org/pdf/2607.04574>
Shows that a small number of on-policy teacher rollouts can dramatically augment agent post-training data, reducing the compute cost of on-policy training while preserving its benefits.
*Why it matters for practitioners:* On-policy data is expensive to collect; this paper gives teams a concrete recipe for harvesting most of the quality gains at a fraction of the rollout budget.

**UCOB: Learning to Utilize and Evolve Agentic Skills via Credit-Aware On-Policy Bidirectional Self-Distillation** — <https://arxiv.org/pdf/2606.29502>
Introduces a credit-aware self-distillation method that lets agents learn which skills to invoke and how to improve them through on-policy experience, without external supervision.
*Why it matters for practitioners:* Skill attribution in multi-step agents is typically a black box; UCOB's credit assignment mechanism makes it possible to audit and improve individual skills rather than treating the agent as monolithic.

**MemGraphRAG: Memory-based Multi-Agent System for Graph Retrieval-Augmented Generation** — <https://arxiv.org/html/2606.00610v1>
Introduces a global memory layer that enforces cross-agent consistency in multi-agent RAG systems, presented at KDD 2026 (Aug 9–13).
*Why it matters for practitioners:* Inconsistent retrieval across agents in a multi-agent RAG pipeline is a real production failure mode; the global memory approach directly addresses how to keep agents aligned on shared facts.
