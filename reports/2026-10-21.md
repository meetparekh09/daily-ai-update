## Trending Papers

**"Not All Test-Time Compute Is Evidence: Model-Specific Bias in LLM Reasoning"** — https://arxiv.org/abs/2610.23213
Demonstrates that repeated sampling from a single reasoning model produces correlated errors rather than independent evidence, and proposes DIA (Diverse Independent Answering) — routing uncertain queries to a small heterogeneous panel of models.
*Why it matters for practitioners:* If you are scaling test-time compute by sampling the same model repeatedly, you are amplifying correlated biases rather than reducing uncertainty; DIA shows a 7% gain on MuSiQue while activating on only ~17% of queries, making heterogeneous ensembling practical.

**"MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents"** — https://arxiv.org/abs/2610.06830
Proposes a policy for dynamic, on-demand memory curation for LLM agents that handles both visual and text modalities, evaluated on five multimodal agent-memory benchmarks.
*Why it matters for practitioners:* Persistent memory management is one of the hardest unsolved problems in production agents; this paper provides a principled framework for deciding what to store, retrieve, and discard — directly applicable to anyone building long-horizon agents.

**"Mixed Precision Scaling Laws for Quantized Pretraining"** — https://arxiv.org/abs/2610.17637
Derives scaling laws for mixed-precision quantized pretraining (varying precision across forward/backward passes), validated on Qwen3 and Llama-style models, and extends to per-layer precision assignment under a compute budget.
*Why it matters for practitioners:* This puts quantized pretraining on the same rigorous footing as the original Chinchilla laws — if you are training or fine-tuning models under a compute budget, this gives you principled guidance on where to spend precision bits.

**"BitNest: Bit-Nested Speculative Decoding for Memory-Efficient LLM Inference Acceleration"** — https://arxiv.org/abs/2610.02800
Combines bit-nested quantization with speculative decoding, achieving a 95.2% average token acceptance rate across 7B–8B models and a 1.48–1.61× speedup over FP16 autoregressive decoding.
*Why it matters for practitioners:* Getting a ~1.5× inference speedup on top of quantization without a meaningful accuracy hit is a meaningful combined win for cost-sensitive serving; the high acceptance rate suggests the quantized draft model is a good proxy for the full model.

**"Building LLM Agent Systems the Deep Learning Way: From Modular Design to Architecture Search"** — https://arxiv.org/abs/2610.04961
Treats LLM agent design as a deep-learning architecture problem — organizing LLM modules into layered structures and applying neural architecture search — reporting performance gains from hierarchical modular design.
*Why it matters for practitioners:* Framing agent design as architecture search is a conceptual shift that makes agent topology something you can optimize systematically rather than tune by intuition, which opens the door to automated agent design tools.
