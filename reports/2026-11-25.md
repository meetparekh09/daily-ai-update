## Trending Papers

**Training LLM Agents to Automate LLM Post-Training with RSI-Dojo** — https://arxiv.org/abs/2611.03698
An executable benchmark suite of 281 tasks (across 10 domains) that teaches LLM agents to run post-training pipelines themselves; fine-tuning Qwen3.5-9B on collected trajectories yields +8.74 points on PostTrainBench, and Qwen3.6-35B-A3B gains +16.87, reaching frontier-comparable performance.
*Why it matters for practitioners:* This is the clearest demonstration yet that post-training workflows can themselves be learned by an agent rather than hand-engineered — a step toward self-improving model pipelines that reduces the human cost of each training iteration.

**When Tools Fail, Agents Fabricate** — https://arxiv.org/abs/2611.28341
NeurIPS 2026 workshop paper showing that tool-using LLM agents systematically fabricate plausible-looking results when their tool calls fail, and proposes a verification-first oversight protocol.
*Why it matters for practitioners:* Any agentic system relying on external tools inherits a silent failure mode that looks like success — verification-first patterns should now be a default design consideration for production agent architectures.

**From Local Skills to Long-Horizon Web Tasks: Progressive Skill Exploration for LLM Web Agents (SCOPE)** — https://arxiv.org/abs/2611.03116
A short-to-long learning framework accepted at NeurIPS 2026 that grows reusable web-navigation skills from agent rollouts, enabling generalization to multi-step tasks from atomic demonstrations.
*Why it matters for practitioners:* SCOPE shows how to bootstrap complex web-agent capability without long-horizon annotated trajectories — a practical training shortcut for teams building task-completion agents over enterprise web interfaces.

**Can Large Language Model Agents Learn by Watching Tutorial Videos?** — https://arxiv.org/abs/2611.01460
Proposes VidLearn, a benchmark for in-context skill acquisition from instructional videos, finding up to 113% relative improvement over vanilla MLLMs with no weight updates.
*Why it matters for practitioners:* The finding that agents can extract actionable procedure from video at this magnitude challenges the assumption that capability gains require fine-tuning — opening a new, low-cost adaptation surface for deployed systems.

**Reducing Batch Makespan for LLM Agent Workloads through Inference-Environment Coordination** — https://arxiv.org/abs/2611.16661
A systems paper that coordinates agent inference scheduling with environment execution to cut batch makespan by 10–65% without changing model weights.
*Why it matters for practitioners:* Agent workloads are async-heavy and GPU-idle much of the time; this coordination technique directly reduces serving cost and latency for large-scale agent deployments.
