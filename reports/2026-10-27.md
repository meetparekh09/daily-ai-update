## Trending GitHub Repositories

**Graphify-Labs/graphify** — <https://github.com/Graphify-Labs/graphify>
Converts a codebase (plus docs, SQL schemas, configs, and PDFs) into an on-device knowledge graph that AI coding assistants query instead of grepping files.
*Why it matters for practitioners:* One benchmark showed a query costing 123 K tokens without the graph and 1.7 K with it—roughly a 70× reduction—meaning agents using Graphify can do deep codebase reasoning within tight context budgets; the Apache 2.0 library supports 17 AI assistants and 36 languages out of the box.

**anthropic-experimental/sandbox-runtime** — <https://github.com/anthropic-experimental/sandbox-runtime>
A lightweight, npm-installable tool that restricts filesystem and network access for arbitrary processes using OS sandboxing primitives (sandbox-exec on macOS, bubblewrap on Linux), without requiring containers.
*Why it matters for practitioners:* Gives teams a standard, Anthropic-vetted way to run untrusted agent-generated code in production with minimal setup—no Docker overhead—and ships as Claude Code's own security backend, so the abstraction is already battle-tested.

**mem0ai/mem0** — <https://github.com/mem0ai/mem0>
A persistent, self-updating memory layer for AI agents that stores and retrieves user preferences, session context, and long-term facts across conversations.
*Why it matters for practitioners:* Stateless chat is the default but rarely the right architecture for production agents; Mem0 provides a drop-in solution for the memory problem that teams are otherwise solving ad-hoc with vector DBs and fragile retrieval heuristics.

**infiniflow/ragflow** — <https://github.com/infiniflow/ragflow>
An end-to-end, document-understanding RAG engine that combines deep-parse OCR, chunk-level citation, and a built-in quality evaluation loop (~82 K stars).
*Why it matters for practitioners:* RAGFlow's chunk-level grounding makes it easier to trace hallucinations to source documents in production, which is the audit requirement most enterprise RAG deployments eventually hit.

**vllm-project/vllm** — <https://github.com/vllm-project/vllm>
High-throughput, memory-efficient LLM inference engine built around PagedAttention, supporting the widest range of production-grade serving backends (~94 K stars).
*Why it matters for practitioners:* It remains the reference implementation for production LLM serving; keeping up with its releases is the fastest way to track the state of the art in throughput and cost per token.

## Trending Papers

**ReTerm: Recovery Training for Self-Improving Terminal Agents** — <https://arxiv.org/abs/2610.18484>
Trains a terminal agent (Qwen3.5-9B) to recover from its own command errors by forking from failure states, generating independent recovery attempts, and rewarding those that pass a task verifier (ReTerm-GRPO).
*Why it matters for practitioners:* Adds 14.6 points on Terminal-Bench 2.0 and 13.2 points on SWE-bench Verified versus the base model—the clearest evidence yet that error-recovery data, not just task-success data, is a distinct and high-value training signal for long-horizon agents.

**OpenMobile-2: An Open Stack for Mobile Agents** — <https://arxiv.org/abs/2610.XXXXX>
Introduces a reproducible mobile-agent training environment using controllable app replicas with programmatic state resets, plus over 300 app-native tools across 50+ apps and a new benchmark; arXiv v1 posted October 9, 2026.
*Why it matters for practitioners:* Open training environments for GUI agents have been the bottleneck; OpenMobile-2 gives teams a full, reproducible recipe—environment + data + training scripts + eval—without relying on closed simulators.

**FOCUS: Active Critic Learning for Long-Horizon Language Model Agents** — <https://arxiv.org/list/cs.AI/2026-10>
A 32-page paper (posted October 26) that trains a separate critic model to assign fine-grained supervision signals at each step of a long-horizon agent trajectory, replacing sparse outcome-level rewards.
*Why it matters for practitioners:* Sparse rewards are the root cause of most agent RL instability; a learned critic that predicts step-level value is a more tractable signal than waiting for task completion, which is the hypothesis this paper evaluates at scale.

**MemPilot: Multimodal Memory Curation for LLM Agents** — <https://huggingface.co/papers>
Proposes a system that automatically curates, structures, and retrieves multimodal (text + image) memories for LLM agents, posted October 5, 2026 on HuggingFace Papers.
*Why it matters for practitioners:* Most memory research focuses on text; MemPilot's multimodal framing is relevant for agents that operate over documents, screenshots, and visual UIs—exactly the environments where today's computer-use agents operate.

**Harness²: Recursive Task-Level Refinement for Agent Execution** — <https://huggingface.co/papers/trending>
A Google paper that improves agent execution harnesses through recursive task-level refinement and continual harness-level learning; reported as the top-upvoted paper on HuggingFace Papers around October 23, 2026.
*Why it matters for practitioners:* Rather than fixing individual task failures, Harness² updates the harness itself—making the agent scaffolding self-improving over time, which directly addresses the toil of manually tuning prompts and tool schemas after each new failure class.
