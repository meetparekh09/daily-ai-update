## Trending Papers

**Agent Safety Should Be a Runtime Contract** — https://arxiv.org/abs/2608.11274
Argues that training-time safety mechanisms (RLHF, DPO, Constitutional AI) are structurally insufficient for autonomous agents that execute code, mutate files, send messages, and modify databases, and proposes that agent safety must instead be enforced by the agent harness at runtime.
*Why it matters for practitioners:* This reframes agent safety as an infrastructure problem—not just a model alignment problem—which changes where teams should invest when hardening production agent deployments.

**AgentSpec: Speculative Decoding for Batch Inference of LLM Agents** — https://arxiv.org/abs/2608.24004
Adapts speculative decoding to high-throughput batch agent serving via a structure-isolated drafting mechanism that addresses high token rejection rates and under-utilized dynamic token budgets under large batch sizes.
*Why it matters for practitioners:* Speculative decoding previously broke down at production batch scales; this paper makes it viable for large-scale agent serving and directly reduces inference latency and cost.

**WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution** — https://arxiv.org/abs/2608.27454
Proposes a system that distills successful agent episodes into a persistent, structured skill library that evolves—becoming more general or specialized—as the agent accumulates experience, resembling a living Wikipedia for agent capabilities.
*Why it matters for practitioners:* Rather than relearning from scratch on every deployment, agents built on this pattern improve over their operational lifetime, which changes the economics and architecture of long-running agent systems.

**How to Train a Critic Stably and Efficiently** — https://arxiv.org/abs/2608.23566
Proposes targeted regularization and update-scheduling techniques that stabilize value function (critic) training in actor-critic LLM fine-tuning pipelines, addressing a key failure mode in RLHF at scale.
*Why it matters for practitioners:* Critic instability is a common blocker when scaling RLHF beyond small models; this gives ML engineers concrete, drop-in techniques to apply when fine-tuning diverges.

**Diagnosing Tool-Selection Reasoning in LLM Agents with Canary Tools** — https://arxiv.org/abs/2608.04719
Introduces diagnostic "canary" probe tools embedded in agent toolsets to surface how models reason about tool selection, paired with a six-category taxonomy of tool-selection reasoning weaknesses benchmarked across frontier LLMs.
*Why it matters for practitioners:* Provides a systematic methodology for auditing whether frontier LLMs actually reason about tools versus pattern-matching on descriptions—critical for anyone deploying tool-using agents at scale.
