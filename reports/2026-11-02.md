## Trending Papers

**DynaFlow: Learning Free-Form Multi-Agent Orchestration** — https://arxiv.org/abs/2610.34467
A framework where a coordinator agent writes task-specific programs to orchestrate fixed sub-agents, achieving 88.08% overall accuracy across six benchmarks on a Qwen3.5-27B backbone — about 10.9 points above the strongest baseline.
*Why it matters for practitioners:* The shift from hand-crafted agent graphs to a learned coordinator that writes its own orchestration programs is a meaningful architectural advance — it separates the coordination logic from the agents themselves and makes complex workflows composable without manual re-engineering.

**Scaling Agent Training Across Execution Harnesses** — https://arxiv.org/abs/2610.29458
Researchers from Renmin University and Beihang show that training an agent in a single fixed execution harness causes systematic overfitting, and propose training across multiple harnesses to improve generalization.
*Why it matters for practitioners:* If your RL-trained agent performs well in testing but degrades in production, harness overfitting is a concrete candidate cause — this paper gives a diagnosis and a remedy that applies to any tool-using agent trained with RL.

**MAS: A Simple and Stable RL Training Recipe for Multi-Agent LLM Systems** — https://huggingface.co/papers
A practical, reproducible reinforcement learning recipe for training multi-agent LLM systems, emphasizing stability over novelty.
*Why it matters for practitioners:* Multi-agent RL training is notoriously fragile; a vetted, stable recipe lowers the barrier for teams that want to apply RL to their own agent networks without building the training loop from scratch.

**When Does Multi-Agent RL Improve LLM Workflows?** — https://huggingface.co/papers
A comparative study examining when shared-policy versus isolated-policy reinforcement learning produces better outcomes in multi-agent LLM setups.
*Why it matters for practitioners:* The answer isn't always "more agents = better" — this paper provides a decision framework for when to invest in multi-agent RL versus simpler single-agent RL, which directly informs architectural choices and compute allocation.

**Harness²: Recursive Agent Harnessing for an Open World** — https://huggingface.co/papers
A Google DeepMind paper (October 9, 2026) proposing a recursive meta-harness that wraps agents in dynamically composed outer harnesses, enabling more flexible open-world task handling.
*Why it matters for practitioners:* The idea that the harness itself can be an agent-directed construct — rather than a static scaffold — is a conceptual shift with broad implications for how enterprise-grade agent systems are designed and composed.
