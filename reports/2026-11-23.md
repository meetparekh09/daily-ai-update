## Trending Papers

**Evolving Infra: Agent-Adaptive LLM Serving at Scale** — https://arxiv.org/abs/2611.12304
Proposes a serving framework that adjusts compute allocation and KV cache management dynamically based on observed agent workload patterns at runtime.
*Why it matters for practitioners:* Agents have fundamentally different request patterns than chatbots — long contexts, variable concurrency, bursty tool calls — and this paper is the first to treat agent-aware serving as a first-class infrastructure problem.

**MEMOIR: A Training-Free Memory Lifecycle for Long-Horizon LLM Agents** — https://arxiv.org/abs/2611.07631
Introduces a lossless, index-free memory management system for LLM agents operating over long horizons, requiring no additional model training.
*Why it matters for practitioners:* Drops a persistent memory layer into an existing agent without fine-tuning cost or infrastructure changes, which directly addresses one of the biggest unsolved problems in production agent deployment.

**RLiD: Reinforcement Learning in the Decision Plane for Language Agents and LLMs** — https://arxiv.org/abs/2611.02455
Reformulates RL for language agents so it optimizes the probability distribution over executable action options rather than raw token probabilities.
*Why it matters for practitioners:* Token-level RL for agents wastes gradient signal on syntactic variance; decision-plane optimization may yield more data-efficient training for action-grounded agent tasks.

**Evolving Agent Harnesses as an Alternative to Fine-Tuning for Domain Specialization** — https://arxiv.org/list/cs.AI/new
Argues that adapting an agent's harness — its tools, prompts, and execution environment — achieves domain specialization without weight updates, based on experiments across several vertical tasks.
*Why it matters for practitioners:* Reframes the default mental model of "domain adaptation = fine-tuning" and suggests that the harness is a first-class optimization target, which has significant cost and iteration-speed implications.

**Potential Emergence in LLM Agents: A Statistical Physics Perspective** — https://arxiv.org/abs/2611.27618
Treats agent intermediate states as measurable variables for characterizing emergent behavior during post-training, with experiments on Qwen3.5-9B agent tasks.
*Why it matters for practitioners:* Offers a principled framework for predicting when and why agent capabilities emerge or collapse during RL post-training, potentially replacing purely empirical evaluation schedules.
