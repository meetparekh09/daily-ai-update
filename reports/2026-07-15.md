## Trending Papers

**MIRIX: Multi-Agent Memory System for LLM-Based Agents** — <https://arxiv.org/abs/2507.07957>
A modular 6-type memory architecture (Core, Episodic, Semantic, Procedural, Resource, Knowledge Vault) coordinated by a multi-agent controller; achieves 35% higher accuracy than RAG on a 20k-screenshot benchmark while using 99.9% less storage.
*Why it matters for practitioners:* Structured multi-type memory outperforms monolithic retrieval at a fraction of the storage cost — the architecture is a concrete template for agent memory design beyond flat vector stores.

**Measuring Harness-Induced Belief Divergence in Multi-Step LLM Agents** — <https://arxiv.org/abs/2607.04528>
Empirically shows that the scaffolding layer (tool prompts, error messages, memory injections) causes systematic drift between what an agent "believes" at step N versus step N+k, compounding reasoning errors in multi-step chains.
*Why it matters for practitioners:* If your agent pipeline is long-horizon, the harness itself — not just the model — is introducing compounding errors; the paper provides diagnostics and mitigation pointers any team can apply.

**Evaluation and Benchmarking of LLM Agents: A Survey** — <https://arxiv.org/abs/2507.21504>
A two-dimensional taxonomy organizing agent evaluation along what to evaluate (behavior, capabilities, reliability, safety) and how to evaluate (interaction modes, datasets, metric computation, tooling), with a focus on enterprise deployment requirements.
*Why it matters for practitioners:* The first survey to separate evaluation design from benchmark selection — provides a structured checklist for teams building eval suites rather than just pointing to existing leaderboards.

**Evidence-Grounded Verified Agentic Reasoning: A Path Toward Eliminating LLM Hallucination in Empirical Inference** — <https://arxiv.org/abs/2607.12650>
Proposes tool-attested kernel proofs — a reasoning protocol where claims made during inference must be anchored to verifiable tool outputs — accepted at the ICML 2026 TAIGR workshop.
*Why it matters for practitioners:* Offers a concrete architectural pattern (not just a training trick) for making agent reasoning auditable and hallucination-resistant in empirical domains like data analysis and scientific QA.

**"The alignment community is unintentionally building a censor's toolkit" (ICML 2026 Outstanding Position Paper)** — <https://icml.cc/virtual/2026/events/2026-position-papers>
Sarah Ball and Phil Hackemann argue that current AI alignment methods — refusal training, activation steering, RLHF preference optimization — are dual-use: the same techniques that block harmful content can suppress legitimate speech when applied by a motivated actor.
*Why it matters for practitioners:* Anyone deploying content-filtering or safety-tuned models at scale is implicitly adopting a censorship infrastructure; the paper surfaces the design decisions that determine whether that infrastructure is used legitimately or abused.
