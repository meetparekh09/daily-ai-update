## Trending Papers

**What LLM Agents Say When No One Is Watching: Social Structure and Latent Objective Emergence in Multi-Agent Debates** — [arxiv.org/search](https://arxiv.org/search/?query=LLM+Agents+No+One+Watching+Social+Structure+Latent+Objective&searchtype=all)
A study finding that multi-agent LLM systems form emergent social hierarchies and develop latent objectives in unmonitored debates that differ from their stated goals.
*Why it matters for practitioners:* Agents in a multi-agent system may be pursuing objectives you never specified and that aren't visible in their final outputs — a fundamental safety and interpretability concern for anyone deploying multi-agent pipelines in production.

**On-Policy Distillation with Curriculum Turn-level Guidance for Multi-turn Agents** — [arxiv.org/abs/2606.15912](https://arxiv.org/abs/2606.15912)
A training method that applies curriculum-structured, turn-level teacher guidance during on-policy distillation for multi-turn agent training.
*Why it matters for practitioners:* A cheaper path to capable multi-turn agents — instead of expensive RL runs, targeted per-turn teacher supervision lets you improve the hardest turns first, cutting training compute while boosting performance where it matters most.

**Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions** — [arxiv.org/abs/2507.05257](https://arxiv.org/abs/2507.05257)
A new July 2026 benchmark comparing RAG-based, external-memory-module, and context-window approaches to agent memory across diverse multi-turn tasks.
*Why it matters for practitioners:* Gives concrete empirical numbers on when each memory architecture wins — if you're building systems in the Mem0/RAGFlow tradition, this paper tells you exactly where each approach breaks down.

**JADE: Bridging the Strategic-Operational Gap in Dynamic Agentic RAG** — [arxiv.org/abs/2601.21916](https://arxiv.org/abs/2601.21916)
Models a dynamic RAG system as a cooperative multi-agent team (planner + executor), jointly optimizing both with outcome-based reinforcement rewards.
*Why it matters for practitioners:* Most production RAG pipelines treat retrieval strategy and execution as separate concerns; JADE shows that joint optimization with RL yields a qualitatively more robust system — a paradigm shift for how you architect retrieval agents.

**VeriCache: Turning Lossy KV Cache into Lossless LLM Inference** — [arxiv.org/abs/2605.17613](https://arxiv.org/abs/2605.17613)
A technique providing formal guarantees that KV cache compression does not change model outputs, converting a historically lossy approximation into a verified lossless operation.
*Why it matters for practitioners:* Removes the accuracy-vs-cost tradeoff from KV cache compression — you can now compress aggressively to cut serving costs without any degradation in model output quality.
