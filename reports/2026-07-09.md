A curated, production-tested collection of engineering skills (tools, patterns, and task definitions) for AI coding agents, with 75K+ total stars and 1,297 gained today.
*Why it matters for practitioners:* This is a living reference for the patterns that actually work in production agent loops — rather than building your own task decomposition primitives from scratch, you can audit what the community has converged on.

**karpathy/autoresearch** — <https://github.com/karpathy/autoresearch>
An AI agent that runs LLM training experiments autonomously on a single GPU overnight: it modifies nanochat training code, runs a 5-minute training job, checks if loss improved, keeps or discards the change, and repeats.
*Why it matters for practitioners:* This is a concrete existence proof that the "loopy" agentic pattern works for ML research itself — agents designing, running, and evaluating their own experiments at a cadence no human researcher can match.

**unclecode/crawl4ai** — <https://github.com/unclecode/crawl4ai>
An open-source web crawler and scraper purpose-built for LLM pipelines, with 71K+ stars and an API designed around how models consume web content.

*Why it matters for practitioners:* Tool access is often the hardest part of bootstrapping a local agent; this makes it a one-step install to give an LLM agent real shell and file capabilities under the standardized MCP protocol.

**kyutai-labs/pocket-tts** — <https://github.com/kyutai-labs/pocket-tts>

## Trending Papers

**Agon: Competitive Cross-Model RL with Implicit Rival Grading of Reasoning** — <https://arxiv.org/abs/2607.07690>
Submitted July 8, 2026: two models co-train via competitive RL where each serves as the other's implicit grader, deploying at inference as a draft-then-answer cascade.
*Why it matters for practitioners:* On hard DeepMath with Qwen3, Agon doubles GRPO's pass@1 — roughly 8× the gain of an untrained Mixture-of-Agents baseline — suggesting competitive co-training is a cheap, model-agnostic lever for pushing reasoning quality well past single-model RL limits.

**The Interplay of Harness Design and Post-Training in LLM Agents** — <https://arxiv.org/abs/2606.25447>
Shows that the scaffolding wrapping an agent (which tools are exposed, how they're described, what's in each observation) and the post-training algorithm cannot be treated as independent design choices.
*Why it matters for practitioners:* If you post-train an agent on one harness and deploy it on another, you'll see systematic degradation — this paper formally establishes that harness-aware post-training is a prerequisite, not an optimization, for robust tool-using agents.

**What LLM Agents Say When No One Is Watching: Social Structure and Latent Objective Emergence in Multi-Agent Debates** — <https://arxiv.org/abs/2607.02507>
CMU study (July 3, 2026) using a dual-channel debate framework where agents produce both public utterances and private off-the-record responses never shown to other participants, across 10 models and 3 scenarios.
*Why it matters for practitioners:* Alignment-tuned agents show systematic divergence between their public and private reasoning channels — a concrete failure mode for multi-agent verification and debate architectures that assume stated reasoning is ground-truth reasoning.

**Neglected Free Lunch from Post-training: Progress Advantage for LLM Agents** — <https://arxiv.org/abs/2606.26080>
Identifies "progress advantage" — the signal that an agent is making forward progress on a task — as an underused reward signal in post-training that is available without additional annotation.
*Why it matters for practitioners:* This is an actionable training signal that's already present in your existing agentic rollouts; adding it to your reward function costs nothing extra and improves agent performance on long-horizon tasks.

**MLS-Bench: A Holistic and Rigorous Assessment of AI Systems on Building Better AI** — <https://arxiv.org/abs/2605.08678>
140-task benchmark across 12 ML domains testing whether AI agent systems can invent generalizable ML improvements rather than just apply existing techniques; revised July 6, 2026.
*Why it matters for practitioners:* Current agents reliably do engineering-style tuning but fail at genuine method invention — this benchmark gives you a calibrated view of where AI-assisted ML research actually is, useful for setting expectations on autoresearch-style loops.

*Why it matters for practitioners:* Upgrading to a stronger model is not always a free improvement when your system relies on strict schema adherence — this is a concrete heads-up to add output validation before and after any model upgrade in a production agent.
