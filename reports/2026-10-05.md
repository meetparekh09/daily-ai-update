## Trending Papers

**RRSI: Regularized Recursive Self-Improvement of Agent Harnesses** — https://arxiv.org/abs/2609.24972
Google Research paper (September 2026) showing that adding regularization to both the proposal and selection stages of evolutionary agent harness optimization prevents overfitting to training tasks, improving held-out performance by up to 2.3 points across coding, agentic workspace, and engineering-design benchmarks.
*Why it matters for practitioners:* Prior harness-evolution methods looked excellent on training tasks and collapsed on unseen ones; this is the first principled, generalizable fix for that failure mode—making automated harness optimization trustworthy enough to deploy.

**Context Language Models** — https://huggingface.co/papers
A framework for building context language models (CLMs) zero-shot from existing pre-trained models, showing they outperform hand-engineered context management strategies across diverse tasks.
*Why it matters for practitioners:* Suggests that treating context management as a learned implicit behavior—rather than an engineered module with explicit retrieval rules—may yield better and architecturally simpler agents.

**Dream-RSI: Recursive Self-Improvement through Evolving Worlds** — https://arxiv.org/pdf/2609.14858
Proposes an RSI framework where the agent recursively generates richer synthetic environments ("worlds") to train against, avoiding the distributional collapse that plagues static-curriculum self-improvement approaches.
*Why it matters for practitioners:* Offers a concrete mechanism for on-policy self-improvement that stays stable by continuously shifting the evaluation distribution—a direct counter to reward hacking in long RSI runs.

**Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness?** — https://arxiv.org/abs/2610.00025
Systematic study of which microtask types in agent harnesses a small language model can handle at parity with a frontier model, with a proposed lightweight eligibility test submitted to NeurIPS 2026 workshop.
*Why it matters for practitioners:* A working eligibility test could replace expensive frontier models with cheap SLMs for a substantial fraction of agent subtasks, cutting inference cost without visible capability regression.

**Heavy-Tailed Memory Traces in Long-Horizon Language Agents** — https://arxiv.org/abs/2610.00010
Analyzes memory access patterns in long-horizon agents, finding they follow a heavy-tailed distribution where a small number of past observations account for the vast majority of retrieved content.
*Why it matters for practitioners:* Justifies architecturally simpler memory systems: if useful content is highly concentrated, retrieval strategies can be aggressively pruned rather than treating all stored observations equally.
