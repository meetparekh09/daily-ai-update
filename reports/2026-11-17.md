## Trending Papers

**Decoupled Predictive Decision Making (DPDM)** — https://arxiv.org/abs/2611.02075
A frozen conditional predictor (LimiX-2) paired with a language-model encoder improves agent mean accuracy from 78.80% to 84.92% across 50 benchmarks with no weight updates.
*Why it matters for practitioners:* Shows that inference-time architectural choice — not fine-tuning — can deliver a consistent +6.12pp lift across a broad benchmark suite; raises the question of whether frozen shared predictors should be a standard slot in agent stacks.

**ModularRSI: Modular and Generalizable Recursive Harness Self-Improvement** — https://arxiv.org/abs/2609.14857
Decomposes an agent harness into five modules (Agent Loop, Tool Use, Observation Management, Context Management, Task Completion Detection) and evolves each independently, raising SWE-bench Verified from 73.4% to 76.5% and cutting average interaction steps ~35%.
*Why it matters for practitioners:* Agents can now improve their own scaffolding rather than just their weights — a shift that makes harness design a tractable optimization target rather than a one-time engineering choice.

**RHO: Retrospective Harness Optimization** — https://arxiv.org/abs/2606.05922
Self-supervised method that tunes the harness using only past trajectories and the agent's own pairwise self-preference, raising SWE-bench Pro pass rate from 59% to 78% in one round.
*Why it matters for practitioners:* No external grader needed — the agent itself provides the signal for harness improvement, making this deployable in environments without labeled ground truth.

**HarnessFix: From Failed Trajectories to Reliable LLM Agents** — https://arxiv.org/abs/2606.06324
Four cooperating LLM agents diagnose harness flaws from failed runs and issue patches, achieving 15–50% performance improvements on SWE-bench Verified, Terminal-Bench 2.0, GAIA, and AppWorld.
*Why it matters for practitioners:* Treats failed runs as debugging data — a practical feedback loop that can be bolted onto any existing agent deployment to continuously improve reliability.

**HarnessX: A Composable, Adaptive, Evolvable Harness Foundry** — https://arxiv.org/abs/2606.14249
A framework for composing and evolving agent harnesses, yielding an average +14.5% gain (up to +44%) across five benchmarks including SWE-bench Verified.
*Why it matters for practitioners:* Positions the harness as a versioned, evolvable artifact — analogous to a software library — rather than a fixed configuration, with practical tooling to manage that lifecycle.
