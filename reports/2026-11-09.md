## Trending Papers

**MEMENTO: Learning Context Management for Long Context Processing Agents** — https://arxiv.org/abs/2611.00244
A Qwen3-8B agent trained to compact its own context window on demand, achieving 67.8% accuracy on 2.5M-token books while never holding more than 20K tokens in context.
*Why it matters for practitioners:* It outperforms a GPT-5.5 agent in the same harness at under 1/50th the cost — a concrete proof-of-concept that training small models to manage their own context is a viable alternative to throwing larger models at long-context tasks.

**AgentBaton: Efficient Model Collaboration in Agentic Tasks** — https://arxiv.org/abs/2610.35959
A lightweight learned detector (NVIDIA Research) that decides when a task is routine enough to hand off from an expensive capable model to a cheaper one mid-execution.
*Why it matters for practitioners:* Reported 66% API cost reduction across 11 model pairs with accuracy gains of up to 8.8 points — the first credible learned routing mechanism for production agent cost optimization.

**Axiomatic RL for Open Multi-Agent Systems** — https://arxiv.org/list/cs.LG/current
A formal reinforcement learning framework for multi-agent settings published at NeurIPS 2026 (arXiv:2611.03301), grounding multi-agent coordination in axioms rather than heuristics.
*Why it matters for practitioners:* Gives multi-agent system designers a theoretically principled vocabulary for reasoning about agent behavior — relevant as agent coordination protocols become a production concern.

**Language Agent Memory: Persistent Preferences and Procedures Across Sessions** — https://arxiv.org/list/cs.CL/current
A cs.CL paper (listed Nov 6 2026) on language agents that maintain persistent memory of user preferences and procedures across separate sessions.
*Why it matters for practitioners:* Directly adjacent to production memory layers like Mem0; formalizes what "agent memory" should store and how it should be retrieved, giving implementors a research baseline to compare against.

**AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement** — https://arxiv.org/abs/2608.20318
A benchmark that gives agents 4 hours to modify training procedures across 10 frozen repositories spanning different algorithm families, measuring whether agents can improve the training algorithm itself.
*Why it matters for practitioners:* Establishes a reproducible standard for testing whether agentic systems can improve ML training pipelines — a prerequisite for any serious work on autonomous AI research infrastructure.
