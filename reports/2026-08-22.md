## Trending Papers

**LLMs Are Not Good Strategists, Yet Memory-Enhanced Agency Boosts Reasoning (EpicStar)** — <https://arxiv.org/abs/2608.12626>
An August 12, 2026 paper showing that a bank of successful past episodes as cross-episode working memory lets an LLM agent dominate StarCraft II at all difficulty levels while using an order of magnitude fewer tokens than CoT-only baselines.
*Why it matters for practitioners:* The result concretely proves that structured cross-episode memory—not more compute or bigger context—is the key missing ingredient for robust long-horizon agent execution, pointing to where to invest in agent architecture.

**Memory-R1: Enhancing LLM Agents to Manage and Utilize Memories via Reinforcement Learning** — <https://arxiv.org/abs/2508.19828>
Trains a Memory Manager agent via RL to issue structured memory operations (ADD, UPDATE, DELETE, NOOP) and achieves state-of-the-art on LoCoMo from only 152 training examples, generalizing to MSC and LongMemEval without retraining.
*Why it matters for practitioners:* 152 examples to SotA performance means this technique is practical to adapt to your own memory schema without large labeled datasets—and the structured ops interface is likely to become the standard API.

**AgentDistill: Training-Free Agent Distillation with Generalizable MCP Boxes** — <https://arxiv.org/abs/2506.14728>
Transfers agent capabilities from a teacher to a student by packaging teacher behavior as reusable MCP modules, with no gradient updates required; evaluated on biomedical and mathematical reasoning benchmarks.
*Why it matters for practitioners:* Training-free distillation means you can compress expensive frontier-agent behavior into a smaller model using only successful trajectories as MCP configs—dramatically cutting inference cost without a fine-tuning pipeline.

**A-RAG: Scaling Agentic Retrieval-Augmented Generation via Hierarchical Retrieval Interfaces** — <https://arxiv.org/abs/2602.03442>
Introduces hierarchical retrieval layers that let an agent decompose multi-hop queries into sub-retrievals, achieving best-in-class performance on 3 of 5 benchmarks with GPT-4o-mini.
*Why it matters for practitioners:* Hierarchical retrieval closes most of the gap between single-hop RAG and full chain-of-thought on complex queries without increasing model size—a practical upgrade path for existing RAG systems.

**Externalization in LLM Agents: A Unified Review of Memory, Skills, Protocols and Harness Engineering** — <https://arxiv.org/abs/2604.08224>
A survey that frames everything an agent "outsources" from its context window—memory stores, skill libraries, MCP protocols, and orchestration harnesses—under a single externalization taxonomy.
*Why it matters for practitioners:* Gives agent builders a shared vocabulary and design checklist for the architectural decisions that most affect reliability and latency in production agent systems.
