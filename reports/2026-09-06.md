## Trending Papers

**CORAL: Long-Running Multi-Agent Systems that Self-Evolve via Shared Persistent Memory** — https://arxiv.org/abs/2604.01658
Proposes a multi-agent framework where agents share a persistent memory pool and iteratively improve coordination, reporting 3–10x performance gains on long-horizon tasks.
*Why it matters for practitioners:* Shared persistent memory as the coordination primitive is a direct architectural alternative to message-passing or centralized orchestration — the 3–10x numbers are large enough to take seriously.

**Combating the Memory Walls: Optimization Pathways for Long-Context Agentic LLM Inference (PLENA)** — https://arxiv.org/abs/2509.09505
Introduces PLENA, a hardware-software co-designed system with flattened systolic-array architecture and asymmetric quantization targeting the memory bandwidth bottleneck in long-context agentic inference.
*Why it matters for practitioners:* As agent loops push context lengths to hundreds of thousands of tokens, this systems-level work shows where the real throughput ceiling is and one credible path past it.

**FastMTP: Accelerating LLM Inference with Enhanced Multi-Token Prediction** — https://arxiv.org/abs/2509.18362
Aligns multi-token prediction (MTP) training with its inference pattern to improve multi-step draft quality, substantially increasing speculative decoding throughput.
*Why it matters for practitioners:* If you're running speculative decoding in production, MTP alignment is a training-time change that improves draft acceptance rates — translating directly to wall-clock latency reduction.

**CSRM: Configurable Safety Reward Model for Balanced Safety Alignment** — https://arxiv.org/html/2605.30487v1
Introduces a reward model conditioned on natural-language safety configurations at inference time, producing scalar rewards for RL fine-tuning without retraining a new reward model for each safety policy.
*Why it matters for practitioners:* Configurable safety policies at inference time mean you can adjust the safety-utility tradeoff without a full RLHF rerun — relevant to any team iterating on alignment for different deployment contexts.

**PaperCompiler: Faithful Paper-to-Code Generation via Repository-Level Specification Compilation** — https://arxiv.org/search/?searchtype=all&query=PaperCompiler
Addresses the gap between paper descriptions and runnable implementations by compiling repository-level specifications to generate faithful, executable code from research papers.
*Why it matters for practitioners:* Reproducibility failures waste significant engineering time when evaluating new methods — a tool that generates faithful scaffolding from the paper itself could meaningfully shorten the research-to-experiment cycle.
