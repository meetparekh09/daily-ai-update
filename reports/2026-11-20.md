**Arbor: How Search Policy Shapes Agent Behavior in System Optimization** — https://arxiv.org/abs/2606.12563
An agent that autonomously generates, tests, and verifies ML training optimizations (DDP flags, fast-path matmuls, in-place ops, fused kernels), achieving +42.8% LLM training throughput and +41% recommendation training speed with no convergence regressions; v2 updated November 17, 2026.
*Why it matters for practitioners:* Agents writing and validating their own training stack improvements — with MLPerf-floor safety checks — signals a real milestone in AI-assisted ML infrastructure work.

**SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training** — https://arxiv.org/abs/2606.02355
A three-phase RL framework in which an agent mines skills from its own successful rollouts, validates them against skill-augmented vs. skill-free rollout pairs, and distills only beneficial skill tokens back into the base policy — so the trained agent runs on the original prompt alone with no skill bank at inference.
*Why it matters for practitioners:* Eliminating skill retrieval at inference cuts latency and context overhead; practitioners training task-specialized agents get a cleaner deployment artifact.

**State2State: Environment-Derived Mid-Training for LLM Agents** — https://arxiv.org/abs/2608.04934
A self-supervised mid-training technique that converts states the agent reaches during exploration into verifiable state-reaching objectives, using rule-based state matching as the reward signal — no expert trajectories or hand-written task labels required.
*Why it matters for practitioners:* This reduces the data bottleneck for training capable agents in new environments; a team can bootstrap a good prior policy from raw environment interaction before any task-specific RL.

**HabitusMem: Belief Memory over Evolving User Preferences for LLM Agents** — https://arxiv.org/abs/2611.25855
Introduces a belief-memory mechanism that tracks and updates user preference models over time, allowing agents to adapt to preference drift rather than treating each session as stateless.
*Why it matters for practitioners:* Most production agent systems either ignore preference drift or rely on crude recency heuristics; structured belief updating is the missing piece for personalization that holds up over weeks.

**LProp: Latent Uncertainty Propagation for Multi-Agent Evidence Chains** — https://arxiv.org/abs/2611.23564
Addresses the problem of LLM agents passing intermediate judgments downstream without attached uncertainty estimates, proposing evidence-conditioned belief revision to propagate latent uncertainty through multi-agent chains.
*Why it matters for practitioners:* In multi-agent pipelines, silent confidence collapse is a major cause of compounding errors; this provides a principled way to surface when a chain's output should not be trusted.
