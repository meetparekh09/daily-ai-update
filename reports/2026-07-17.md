## Trending Papers

**CompactionRL: Reinforcement Learning with Context Compaction for Long-Horizon Agents** — https://arxiv.org/abs/2607.05378
Jointly trains task execution and context summarization using token-level loss normalization and cross-trajectory GAE so the model learns to act on its own compacted histories, gaining 7.0 points absolute on SWE-bench Verified for GLM-4.5-Air.
*Why it matters for practitioners:* The core production bottleneck for long-running coding agents is context management — this paper shows you can train the compressor and the agent together rather than bolting on a post-hoc summarizer.

**Governance Decay: How Context Compaction Silently Erases Safety Constraints in Long-Horizon LLM Agents** — https://arxiv.org/abs/2606.22528
Demonstrates that context compaction drops in-context safety policies (compressors treat standing instructions as low-salience), raising constraint-violation rates from 0% to 30–59% across 7 models and 1,323 episodes; proposes Constraint Pinning as a ~47-token training-free fix.
*Why it matters for practitioners:* If your agent uses context compaction and you have safety or behavioral constraints in the system prompt, this paper says they are likely being silently dropped — the fix is immediate and cheap.

**Knowledgeless Language Models: Suppressing Parametric Recall for Evidence-Grounded Language Modeling** — https://arxiv.org/abs/2607.12831
Pretrains LLMs on corpora with anonymized named entities, forcing the model to rely on provided context rather than memorized facts; KLLMs outperform matched baselines on contextual QA, fact verification, and hallucination detection.
*Why it matters for practitioners:* This reframes base model selection for retrieval-heavy products — parametric knowledge can actively hurt RAG systems, and training it out from the start is now a demonstrated alternative.

**Unified Data Selection for LLM Reasoning** — https://arxiv.org/abs/2605.22389
Establishes HES (Hardness-Efficiency-Sufficiency) as a training-free metric that unifies data selection for long-CoT reasoning training, matching or exceeding expensive compute-heavy filtering methods.
*Why it matters for practitioners:* Anyone fine-tuning models for agentic reasoning tasks can use HES to replace expensive data-filtering iterations — directly reduces the cost and time of building domain-specific reasoning datasets.

**Rethinking Code Performance Benchmarks for LLMs** — https://arxiv.org/abs/2607.07619
Re-runs 1,538 tasks from four popular code efficiency benchmarks (EffiBench, Enamel, EvalPerf, Mercury) with 30 iterations and statistical testing, finding only 6.11% of "performant" implementations are significantly faster than canonical solutions.
*Why it matters for practitioners:* If your team uses code efficiency benchmarks to evaluate coding agents, this paper says you are likely measuring statistical noise — the benchmark landscape for agent code generation needs to be rebuilt.
