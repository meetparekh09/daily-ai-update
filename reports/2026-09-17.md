## Trending GitHub Repositories

**karpathy/autoresearch** — [https://github.com/karpathy/autoresearch](https://github.com/karpathy/autoresearch)
An agent harness that runs autonomous ML experiments on a single GPU overnight: modify code, train for 5 minutes, check if validation loss improved, repeat — with zero human intervention, it discovered 20 optimizations that cut the Time-to-GPT-2 benchmark from 2.02 h to 1.80 h (11% improvement).
*Why it matters for practitioners:* This is the clearest live demo of on-policy self-improvement applied to model training — if you're running any repeated training ablations, this pattern scales directly to your setup.

**stablyai/orca** — [https://github.com/stablyai/orca](https://github.com/stablyai/orca)
An Agent Development Environment (ADE) for running fleets of parallel coding agents (Claude Code, Codex, and 30+ others) simultaneously across Git worktrees, with a unified orchestration UI — now at 67k+ stars.
*Why it matters for practitioners:* Orca makes the multi-worktree parallel-agent pattern that's been discussed in theory into a first-class tooled workflow; if you're building agent pipelines that require parallel exploration, this is the reference implementation.

**affaan-m/ECC** — [https://github.com/affaan-m/ECC](https://github.com/affaan-m/ECC)
A performance optimization system for coding agents (Claude Code, Cline, etc.) covering skills, instincts, persistent cross-session memory, and security boundaries — 5,292 new stars in the past week.
*Why it matters for practitioners:* The persistent-memory + security framing directly addresses the two main weaknesses of stateless coding agents in production; the combination maps precisely to what Mem0 showed was needed for multi-session agent reliability.

**alibaba/open-code-review** — [https://github.com/alibaba/open-code-review](https://github.com/alibaba/open-code-review)
A hybrid code review tool combining deterministic static pipelines with LLM agents, battle-tested at Alibaba's internal scale — fastest weekly riser in the LLM infra space at 8,594 new stars.
*Why it matters for practitioners:* The hybrid architecture (rules for what rules know, agents for what they don't) is the production pattern that makes LLM code review reliable rather than probabilistic; this is an open-sourced version of how a tier-1 company actually ships it.

**Tencent/WeKnora** — [https://github.com/Tencent/WeKnora](https://github.com/Tencent/WeKnora)
An open-source LLM knowledge platform that transforms raw documents into three artifacts simultaneously: a queryable RAG system, an autonomous reasoning agent, and a self-maintaining wiki.
*Why it matters for practitioners:* The three-artifact output from a single document ingestion pipeline is a strong design pattern for enterprise RAG — building all three as a unit solves the stale-index problem that plagued first-gen RAG deployments.

## Trending Papers

**NCP-ArchPreview Technical Report: Moving towards Latent Space Language Models through Next Concept Prediction** — [https://arxiv.org/abs/2609.10715](https://arxiv.org/abs/2609.10715)
An 8.9B-parameter model pretrained on latent concept tokens rather than raw word tokens, achieving the same final loss as OLMo-3-7B while consuming only 51.3% of the training tokens, with a +5.99-point gain on GSM8K.
*Why it matters for practitioners:* This is the most credible challenge to next-token prediction as the only pretraining objective at meaningful scale — if concept-level prediction halves compute cost for equivalent downstream quality, pretraining pipelines will need to reckon with it.

**LLMZero: Discovering Adaptive Training Strategies for RL Post-Training via LLM Agents** — [https://arxiv.org/abs/2606.18388](https://arxiv.org/abs/2606.18388)
An agentic system that optimizes RL post-training by running tree search over training checkpoints, diagnosing pathologies, and proposing multi-parameter transitions — improving over the base model by 9–140% and over grid search by 6–15%.
*Why it matters for practitioners:* Using agents to find better training hyperparameter schedules outperforms human-designed grid search; this suggests that the next step in post-training is not more manual ablations but automated agent-driven exploration.

**SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training** — [https://arxiv.org/pdf/2606.02355](https://arxiv.org/pdf/2606.02355)
A training framework where LLM agents learn reusable intrinsic skill representations via self-internalization, reducing dependence on externally designed reward functions during RL fine-tuning.
*Why it matters for practitioners:* If agents can bootstrap skill libraries from their own trajectories without hand-crafted reward shaping, it substantially lowers the engineering cost of training specialized agents for new domains.

**Retrospective Progress-Aware Self-Refinement for LLM Agent Training** — [https://arxiv.org/abs/2606.14302](https://arxiv.org/abs/2606.14302)
A framework (RePro) that trains agents to self-generate progress signals via a forward-then-reflect rollout paradigm, initialized with minimal external demonstrations and further trained with a composite reward — requiring far fewer labeled examples than standard RLHF.
*Why it matters for practitioners:* The ability to bootstrap progress signals from minimal demonstrations directly addresses the data-labeling bottleneck in supervised agent training pipelines.

**StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction** — [https://arxiv.org/pdf/2605.06642](https://arxiv.org/pdf/2605.06642)
A method that abstracts multi-turn agent trajectories into strategic summaries as the RL reward signal, reducing noise in long-horizon credit assignment and improving multi-step task completion.
*Why it matters for practitioners:* Long-horizon credit assignment is one of the core unsolved problems in agentic RL; using trajectory abstractions rather than per-step rewards is a simple intervention that practitioners can add to existing training pipelines.
