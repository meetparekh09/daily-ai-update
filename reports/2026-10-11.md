## Trending Papers

**CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling** — https://arxiv.org/abs/2610.06829
Proposes using conformal prediction to generate cheap, reliable step-level training signals for web agents, addressing the bottleneck of sparse and expensive reward signals during training.
*Why it matters for practitioners:* Sparse training signals and costly judges are the primary blockers for training capable web agents at scale; CLIFT's conformal-verification approach offers a way to generate dense supervision without a heavy oracle at every step.

**MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents** — https://arxiv.org/abs/2610.06830
Introduces a memory architecture for LLM agents that curates memory on demand based on query relevance, rather than storing everything or discarding aggressively.
*Why it matters for practitioners:* Query-agnostic memory systems are a persistent pain point in production agents; MemPilot's on-demand curation model directly reduces both irrelevant context noise and critical-detail loss.

**T2SPO: Policy Optimization for Agentic Reinforcement Learning** — https://arxiv.org/list/cs.LG/current
Proposes a new policy optimization method specifically designed for the long-horizon, multi-step nature of agentic RL tasks.
*Why it matters for practitioners:* Standard RL algorithms are poorly adapted to agentic settings where credit assignment spans many steps; T2SPO is an indicator of where RL-for-agents training is heading.

**OnTrack: Real-Time Monitoring for LLM Agents** — https://arxiv.org/list/cs.AI/current
Introduces a scalable approach for real-time monitoring of LLM agent behavior, with a focus on detecting deceptive or out-of-bounds actions mid-execution.
*Why it matters for practitioners:* As agents gain longer autonomy windows, monitoring becomes a production reliability problem rather than a research problem; OnTrack's approach points to a deployable oversight pattern.

**EVA: Evolving Agents via Pseudo-Symbolic Abstraction** — https://aclanthology.org/2026.acl-long.754
Proposes a paradigm for agents that autonomously learn and update their own behavioral policies through symbolic abstraction rather than full retraining.
*Why it matters for practitioners:* Self-improving agents that update without retraining are a prerequisite for persistent, long-lived agent deployments; EVA's abstraction mechanism offers a concrete path toward that without full fine-tuning overhead.
