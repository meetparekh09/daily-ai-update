## Trending Papers

**"Your Agent's Memories Are Not Its Own: Forged Reasoning Attacks on LLM Agent Memory and Defenses"** — https://arxiv.org/abs/2607.05029
Introduces FARMA (Forged Amplifying Rationale Memory Attack), which poisons an agent's persistent memory by injecting forged reasoning histories that cause the agent to consistently make wrong decisions while appearing to follow correct logic.
*Why it matters for practitioners:* Any production agent that stores and retrieves past reasoning (not just facts) is vulnerable to this class of attack — it invalidates the assumption that memory-augmented agents can safely trust their own history.

**"Beyond GRPO and On-Policy Distillation: An Empirical Sparse-to-Dense Reward Principle for Language-Model Post-Training"** — https://arxiv.org/abs/2605.12483
Shows that replacing sparse (binary correct/incorrect) rewards with a graduated sparse-to-dense reward schedule during post-training consistently outperforms both GRPO and on-policy distillation baselines on reasoning benchmarks.
*Why it matters for practitioners:* A simple reward-shaping change that beats the two dominant post-training paradigms without additional data or compute is directly actionable for any team running RLHF or distillation pipelines.

**"EvoAgentBench: Benchmarking Agent Self-Evolution via Ability Transfer"** — https://arxiv.org/abs/2607.05202
A benchmark spanning web research, algorithmic reasoning, software engineering, and knowledge work that tests whether agents can genuinely improve by transferring learned abilities across tasks — finding that no current automatic method sustains positive gain in all settings.
*Why it matters for practitioners:* The finding that self-evolution doesn't yet generalize is a concrete counterweight to optimism about autonomous agent improvement loops; it identifies experience encoding and routing as the specific failure modes to fix.

**"HAS-Bench: Evaluating LLM-Based Human-Agent Systems under Configurable Human Participation"** — https://arxiv.org/abs/2607.04329
A benchmark that systematically varies the level and form of human participation in agent tasks (from fully autonomous to heavily supervised), measuring how task success, quality, and collaboration dynamics change across GPT-4.1, Claude-Sonnet-4, DeepSeek-V3, and Llama-3.1-8B.
*Why it matters for practitioners:* It provides the first systematic evidence for how much human-in-the-loop involvement actually helps (and when it doesn't), giving teams a principled basis for choosing automation level in production deployments.

**"Rethinking the Evaluation of Harness Evolution for Agents"** — https://arxiv.org/abs/2607.12227
Analyzes the methodological gaps in how agent harness architectures are currently evaluated as they evolve, arguing that aggregate accuracy comparisons fail to diagnose where harness changes actually drive improvement.
*Why it matters for practitioners:* As harness engineering matures into its own discipline, having a rigorous evaluation framework is prerequisite for distinguishing harness improvements from model improvements — a distinction most current evals collapse.
