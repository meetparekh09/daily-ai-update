## Trending Papers

**Architectural Design, Not Only Model Intelligence, Governs Multi-Agent LLM Performance** — https://arxiv.org/abs/2602.03128v2
SIGMOD 2027 paper empirically showing that multi-agent system architecture (routing, coordination patterns) matters as much as base model capability for task outcomes.
*Why it matters for practitioners:* Challenges the assumption that upgrading the underlying model automatically improves a multi-agent system — routing logic and coordination structure deserve the same engineering attention as model selection.

**SFT or RL for Tool-Calling Agents? A Controlled Study Across Data, Method, and Scale** — https://arxiv.org/abs/2609.17848v1
Controlled comparison of supervised fine-tuning vs. reinforcement learning for training tool-calling agents across data regimes and model scales (REALM@EMNLP 2026).
*Why it matters for practitioners:* Concrete guidance: RL wins at scale but SFT is more data-efficient at small scale — gives teams a principled decision framework before committing fine-tuning budget.

**Do Not Restart: Residual Completion for Stateful Agent Handoffs** — https://arxiv.org/abs/2609.13800v2
Introduces "residual completion" — preserving partial execution state during agent handoffs so sessions continue rather than restart from scratch.
*Why it matters for practitioners:* Stateful handoffs are an unsolved operational problem in most production multi-agent systems; this paper introduces a concrete representation that could significantly reduce redundant computation across agent boundaries.

**One Size Does Not Fit All! Dynamic Retriever and Generator Selection for RAG** — https://arxiv.org/abs/2609.17709v1
Per-query adaptive selection of both the retriever and generator component in RAG pipelines, outperforming static configurations across diverse query types.
*Why it matters for practitioners:* Most RAG deployments pick one retriever and one generator globally — this shows that routing these dynamically per query type yields measurable gains, a pattern worth plumbing into production RAG infra.

**Accelerating Dense LLMs via L0-regularized Mixture-of-Experts** — https://arxiv.org/abs/2609.21672v1
Converts dense transformer layers into sparse MoE layers during training using L0 regularization, reducing active parameter count at inference without standard MoE routing instability.
*Why it matters for practitioners:* Offers a path to MoE-level inference efficiency starting from a dense model checkpoint, without the load-balancing failures that plague standard MoE training — directly relevant for teams fine-tuning and serving large models.
