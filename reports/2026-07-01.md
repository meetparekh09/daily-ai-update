## Trending Papers

### 1. [Unlimited OCR Works: Welcome the Era of One-shot Long-horizon Parsing](https://arxiv.org/abs/2606.23050)
Introduces Reference Sliding Window Attention (R-SWA) enabling efficient multi-page OCR transcription in a single forward pass using a 3B-parameter MoE model with constant KV cache.

### 2. [DeepAnalyze: Agentic Large Language Models for Autonomous Data Science](https://arxiv.org/abs/2510.16872)
First agentic 8B-parameter LLM for end-to-end autonomous data science — raw data in, professional research reports out — without external orchestration frameworks.

### 3. [Textual Belief States for World Models: Identifiable Representation Learning Under Strict Mediation](https://arxiv.org/abs/2606.27681)
Addresses identifiable representation learning in text-based world models by enforcing strict latent state mediation, improving predictive performance in partially observed LLM-based environments.

### 4. [A Dataset of Agentic AI Coding Tool Configurations](https://arxiv.org/abs/2605.08435)
Large-scale empirical study of 2,303 agent context files from 1,925 repositories, documenting how modern AI coding assistants decompose natural language goals into executable multi-step tasks.

### 5. [Agent Skills for Large Language Models: Architecture, Acquisition, Security, and the Path Forward](https://arxiv.org/abs/2602.12430)
Comprehensive framework for LLM agent skill development and meta-learning, covering architecture patterns, security considerations, and scalable agent capability evolution.

### 6. [SwarmAgentic: Towards Fully Automated Agentic System Generation via Swarm Intelligence](https://arxiv.org/abs/2506.15672)
PSO-inspired framework that constructs and jointly optimises multi-agent systems from scratch through language-driven exploration, evaluated on six open-ended real-world tasks.

### 7. [LiteResearcher: A Scalable Agentic RL Training Framework for Deep Research Agent](https://arxiv.org/abs/2604.17931)
Decouples synthetic data generation from real-world search during RL training to stabilise deep research agents — LiteResearcher-4B achieves 71.3% on GAIA and 78.0% on Xbench (open-source SOTA).

### 8. [Self-Evolving Multi-Agent Systems via Textual Backpropagation](https://arxiv.org/pdf/2506.09046)
Multi-agent systems that improve their own inter-agent communication protocols using gradient-free textual backpropagation — a step toward self-improving agent teams.
