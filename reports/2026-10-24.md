## Trending Papers

**Librarian Agents: Training LLMs to Curate Long-Context Workspaces that Anticipate Future Queries** — https://arxiv.org/abs/2610.22273
Trains a builder policy with RL to transform raw documents into a hierarchical filesystem with synthetic summaries and cross-reference links, which a separate reader agent then uses as its workspace; reports +33pp over best RAG/precompute baselines on BrowseComp-Plus.
*Why it matters for practitioners:* Flips the traditional RAG pattern—instead of retrieving at query time, the agent proactively structures knowledge at ingest time, amortizing cost and enabling far richer cross-document reasoning.

**Agent-Reflex: Teaching Language Agents to Act Reflectively** — https://arxiv.org/abs/2610.17953
A three-stage training framework (skill discovery from matched success/failure pairs → reflective SFT → on-policy reflective policy optimization) targeting agents operating under noisy tool feedback and mid-task user corrections; scores 58.6 on five long-horizon tool-use benchmarks.
*Why it matters for practitioners:* Directly addresses the failure mode where an agent gets stuck in an error loop because it can't distinguish transient noise from a genuine mistake—a persistent pain point in production tool-use agents.

**Harness²: Recursive Agent Harness Refinement** — https://huggingface.co/papers
Improves agent execution harnesses through recursive task-level refinement and continual harness-level learning without requiring ground-truth verifiers; appeared on the Hugging Face trending papers page in early October.
*Why it matters for practitioners:* Suggests that the scaffolding around an agent (the harness, the prompt structure, the tool definitions) can itself be learned and improved automatically—shifting some of the painful prompt-engineering work to training time.

**Training LLMs for Multi-Agent Collaboration with Verifiable Information Rewards** — https://arxiv.org/abs/2610.17893
Introduces a reward signal derived from verifiable information exchange between agents, enabling RL-based multi-agent training without human-labeled data for the coordination step.
*Why it matters for practitioners:* Gives a concrete, scalable training recipe for multi-agent systems where inter-agent grounding is the bottleneck, rather than individual agent capability.

**LoGRA: Scaling LLM Reinforcement Learning with Low-Rank Gradient Sketches** — https://huggingface.co/papers
Reduces the memory and compute cost of RL post-training via low-rank gradient approximations, reported as part of the October HuggingFace daily papers community.
*Why it matters for practitioners:* Makes RL-based post-training accessible on smaller GPU budgets, which lowers the barrier for teams that want to fine-tune reasoning or instruction-following behavior without A100-scale clusters.
