## Trending Papers

**EarlyEval: Cheaper Agent Evaluation via Early Outcome Prediction** — https://arxiv.org/abs/2609.02783
Introduces "early outcome prediction" to cut agent evaluation cost by predicting final task outcomes from intermediate trajectory signals — eliminating 13–26% of agent steps and up to 44% of input tokens at 89–97% accuracy on SWE-bench and related benchmarks.
*Why it matters for practitioners:* Running a frontier agent benchmark pass can cost hundreds to thousands of dollars; this method halves that cost without distorting final scores, making iterative agent development economically viable.

**Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems** — https://arxiv.org/abs/2609.00237
Proposes learned Memory Write and Retrieval Gates that commit only non-redundant reasoning steps and supply each agent a compact, relevant memory subset — replacing hand-crafted summarization rules in multi-agent orchestration.
*Why it matters for practitioners:* Context bloat and irrelevant memory injection are the top performance and cost killers in multi-agent pipelines; learned gating adapts to task distribution in a way fixed summarization never can.

**Invalidation Contracts for Cross-Episode Agent Memory** — https://arxiv.org/abs/2609.00243
Introduces formal specifications defining when stored agent memory should be treated as stale and discarded across separate conversation episodes — addressing the under-studied problem of persistent memory introducing confident but wrong beliefs.
*Why it matters for practitioners:* Any production long-lived agent (customer service, personal assistant) will eventually serve stale facts as current truth; this paper provides a systematic design pattern replacing ad-hoc TTL hacks.

**Skill Following: Evaluating Actual Skill Use in Retrieval-Enabled LLM Agents** — https://arxiv.org/abs/2609.00549
Reveals that existing RAG-agent benchmarks measure retrieval quality but not whether the agent actually followed and correctly applied the retrieved skill — introduces a new evaluation protocol isolating skill-following compliance.
*Why it matters for practitioners:* High retrieval recall scores may be masking poor skill utilization — a distinct failure mode requiring different fixes (better instruction-following, not better retrieval); this benchmark makes that gap measurable.

**Retrospective Progress-Aware Self-Refinement for LLM Agent Training** — https://arxiv.org/abs/2606.14302
A "forward-then-reflect" rollout paradigm where the agent executes actions, then retrospectively reassesses step-wise progress given the completed trajectory and known outcome — generating training data without human annotation or a strong critic model.
*Why it matters for practitioners:* Provides a low-annotation-cost path to iteratively improving agents on real task distributions — the retrospective signal is more informative than process reward models trained on human labels, and cheaper.
