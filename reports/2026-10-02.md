## Trending Papers

**Context Language Models** — https://arxiv.org/html/2609.37725v1
Introduces LMs that have native write access to their own live context window, enabling on-the-fly context compression, reordering, and restructuring without relying on static prompting strategies.
*Why it matters for practitioners:* Long-running agents today rely on external summarization hacks to manage context bloat; CLMs make context management a first-class model capability, which changes the architecture for any agent with a long operational horizon.

**PACE: Provenance-Aware Capability Enforcement for Tool-Using LLM Agents** — https://arxiv.org/abs/2610.01349
Tracks the provenance of every instruction flowing into a tool-using agent and enforces capability restrictions based on origin, preventing poisoned tool outputs from escalating agent permissions.
*Why it matters for practitioners:* Prompt injection through tool results (a web page, a database row, an API response) is currently the most underdefended attack surface in production agents; PACE is the first enforcement-layer design with a formal provenance model.

**TRACE: Trajectory Return Attribution and Contrastive Erasure for Multi-Turn Safety** — https://arxiv.org/abs/2610.01323
Attributes harmful outcomes in multi-turn agent conversations to specific trajectory steps, then uses contrastive erasure to prevent harmful goals from propagating through subsequent turns.
*Why it matters for practitioners:* Blanket multi-turn safety refusals break legitimate long-running tasks; TRACE enables surgical, step-level intervention — the right tool for agents that need to continue operating after detecting a problematic turn.

**DeFA: Dependency-Guided Failure Attribution for LLM Agents** — https://arxiv.org/abs/2610.01256
Combines protocol state tracking with dependency graphs to automatically localize errors in multi-step agent pipelines to the exact failing step and its root-cause dependency.
*Why it matters for practitioners:* Debugging a 30-step agent failure today requires replaying the full trace; DeFA narrows the search to a single node in the dependency graph, which changes the economics of production agent debugging.

**Verify Claims, Not Scores: Evidence-Based Verification of Modular Agents** — https://arxiv.org/abs/2610.01348
Proves formally that aggregate task scores cannot identify which module of a modular agent is responsible for a failure, and proposes evidence-based per-component verification as the correct unit of measurement.
*Why it matters for practitioners:* If your agent eval returns 82% on a benchmark, this paper explains why you still cannot decide what to fix — and what you should measure instead; relevant to anyone designing evals for RAG pipelines, tool-use agents, or multi-module systems.
