## Trending Papers

**MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents** — <https://arxiv.org/abs/2610.06830>
An RL-trained multi-step agent policy that decides at each step whether to retrieve from existing memory or trigger a new curation pass across heterogeneous LLMs/VLMs, beating cost-latency-performance trade-off baselines on five benchmarks.
*Why it matters for practitioners:* Frames memory in agents as a dynamic routing problem rather than a fixed retrieval step — directly actionable for teams building long-horizon agents on top of memory layers like Mem0.

**Learning to Act with Task Progress (arXiv:2610.10332)** — <https://arxiv.org/abs/2610.10332>
Proposes distilling compact teacher supervision into small agents using task-progress signals, achieving strong performance without full trajectory imitation.
*Why it matters for practitioners:* On-policy distillation with progress-shaped rewards sidesteps the compounding-error failure mode of naive behavior cloning — a practical training recipe for teams trying to shrink expensive frontier-model agents.

**Agentic AutoRAG (arXiv:2610.08452)** — <https://arxiv.org/abs/2610.08452>
Applies reasoning agents to automatically configure and optimize complete RAG pipelines, with code released under Apache 2.0.
*Why it matters for practitioners:* Turns RAG tuning — typically a manual, brittle process — into a learnable optimization problem, directly reducing the engineering burden of maintaining production retrieval systems.

**Training Advisors for LLM Agents from Task Outcomes (arXiv:2610.09858)** — <https://arxiv.org/abs/2610.09858>
A 26-page method for training lightweight "advisor" models from downstream task outcomes that guide LLM agent decisions without requiring dense supervision.
*Why it matters for practitioners:* Advisor models trained on outcome signals (not step-by-step labels) are much cheaper to produce and update — a credible path for continuously improving deployed agents.

**Distilling LLM Reasoning with Worst-Case Constrained Reinforcement Learning (arXiv:2610.00332)** — <https://arxiv.org/abs/2610.00332>
Trains a student model to match a teacher's reasoning under adversarially chosen worst-case scenarios using a constrained RL objective.
*Why it matters for practitioners:* Worst-case constraints during distillation improve robustness on hard edge-cases that standard imitation misses — relevant for any team using RL-based distillation to compress reasoning models.
