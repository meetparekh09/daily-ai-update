## Trending Papers

**AutoRAGBench: A Benchmark for LLM Agents Automating RAG System Development** — https://arxiv.org/abs/2611.25582
A benchmark of nine end-to-end RAG development tasks, each giving agents a six-hour compute budget and no starter code; the top LLM agent configuration scored 56.1 versus a 44.4 human-SOTA composite baseline.
*Why it matters for practitioners:* Agents can now outperform humans at the full RAG-system construction loop, which means the bottleneck in standing up a new RAG application is shifting from engineering time to agent quality and prompt design.

**HabitusMem: Belief Memory over Evolving User Preferences for LLM Agents** — https://arxiv.org/list/cs.AI/new
A memory architecture where an agent maintains an explicit belief model of a user's preferences and updates it over time as behavior shifts, rather than naively appending interaction history.
*Why it matters for practitioners:* Agents deployed to real users need memory that handles preference drift—this paper gives a concrete mechanism for doing that without ballooning context costs.

**QDA: Closed-Loop LLM Quantization Design with Agents** — https://arxiv.org/list/cs.LG/current
An agent-in-the-loop framework that iteratively proposes, evaluates, and refines quantization configurations for LLMs, replacing a manual hyperparameter search.
*Why it matters for practitioners:* The pattern—agent proposes config, runs eval, reflects on result, iterates—is directly reusable for any optimization task where the evaluation is expensive but automatable.

**Clover-35B-A3B-Preview: Toward Generalized Coding with Our First Loop Transformer** — https://simonwillison.net/2026/Nov/23/glm-54/
A mixture-of-experts diffusion language model from Z.ai with 35B total / 3B activated parameters, notable as the first production model using a looped (recurrent) transformer architecture with thinking-mode generation.
*Why it matters for practitioners:* The looped transformer design is a live experiment in whether recurrence-at-inference-time can close the gap between diffusion LMs and autoregressive models on complex reasoning—worth watching as an architectural signal.

**Potential Emergence in LLM Agents: A Statistical Physics Perspective** — https://arxiv.org/abs/2611.27618
A theoretical framework (submitted Nov 20) that models the state transitions in LLM agent reasoning as a global potential function, borrowing tools from statistical physics to explain how coherent behavior emerges across reasoning steps.
*Why it matters for practitioners:* Gives a formal handle on why agent reasoning "clicks" or "fails"—useful for anyone trying to understand the conditions under which chain-of-thought and self-reflection reliably produce correct outputs.
