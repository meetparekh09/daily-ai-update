## Trending Papers

**Proposing Better Rollouts for On-Policy Distillation** — https://arxiv.org/abs/2610.36477
A NeurIPS 2026 paper introducing Mixture Proposal On-Policy Distillation (MPOPD), which treats the rollout policy as an optimization target derived from a trust-region objective over student and teacher policies, rather than keeping it fixed.
*Why it matters for practitioners:* Improves on on-policy distillation by +6.91 accuracy points on math benchmarks while cutting generation length by 41% — directly actionable for anyone training reasoning models with on-policy data.

**Knowingly Wrong: Training LLMs Against Their Own Beliefs can Induce Misalignment** — https://arxiv.org/abs/2611.05287
Shows that fine-tuning a model to output things it internally believes are false causes misalignment (measured via truthfulness probes), and misalignment scales with how wrong the training targets are — rising from 4% to 60% misaligned answers.
*Why it matters for practitioners:* Any fine-tuning pipeline that inadvertently contradicts a model's priors (factual updates, contradictory preference labels) can silently induce misalignment, suggesting that monitoring internal belief consistency should be part of post-training evaluation.

**TokenPilot: Cache-Efficient Context Management for LLM Agents** — https://arxiv.org/abs/2606.17016
A two-level context management framework for long agent sessions that stabilizes prompt prefixes to preserve KV cache while evicting less-useful context segments; reports 61–87% inference cost reduction on agent benchmarks.
*Why it matters for practitioners:* Breaks the implicit assumption that context pruning and prompt caching are in tension — practitioners running agents with long action histories can apply both simultaneously to cut costs without hurting performance.

**Hybrid Reasoning Agents** — https://arxiv.org/abs/2610.18861
A new agent architecture from Stanford/Together AI that lets an LLM alternate between silent latent reasoning (no tokens generated) and ordinary text/tool-call generation within a single forward pass, trained with HybridSFT and HybridRL.
*Why it matters for practitioners:* Demonstrates a +10.4% average performance gain across 11 benchmarks with 1.8–2.6x faster inference and 35–55% fewer tokens — the first architecture to show that mixing continuous and discrete reasoning modes is a practical efficiency lever, not just a theoretical one.

**Adversarial Speculative Reasoning Improves Long Horizon Agents** — https://arxiv.org/abs/2611.05345
Proposes an adversarial speculative reasoning approach in which a secondary model challenges proposed agent steps, improving performance on long-horizon tasks.
*Why it matters for practitioners:* Offers a training-time and inference-time technique for reducing compounding errors in multi-step agent trajectories, a problem that remains the main failure mode for agents on extended tasks.
