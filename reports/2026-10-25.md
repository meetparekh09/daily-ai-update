## Trending Papers

**Harness²: Recursive Agent Harnessing for an Open World** — https://arxiv.org/abs/2610.14224
From Google Cloud AI Research and Northwestern; proposes a two-level self-improvement loop where agents refine their own execution harnesses using contrastive behavioral probes (no ground-truth verifiers required), then learn reusable meta-patterns across tasks.
*Why it matters for practitioners:* Breaks the circular dependency that has blocked self-improving agents—you no longer need a verifier oracle to improve the harness, and the approach yielded up to 11.8 pp gains on WorkBuddy-Bench and LAB.

**LivingRAG: Augmenting Graph RAG with Experience** — https://arxiv.org/abs/2608.25960
Adds episodic memory to graph-structured RAG: the system accumulates past retrieval experiences and uses them to inform future retrievals, progressively improving without retraining the underlying model.
*Why it matters for practitioners:* Static knowledge graphs degrade on distribution shift; LivingRAG's experience layer is a concrete mechanism for making graph RAG systems self-correcting in production.

**TokenPilot: Cache-Efficient Context Management for LLM Agents** — https://arxiv.org/abs/2606.17016
A context management layer for multi-agent pipelines that maximizes KV-cache reuse across shared prefixes, tool-call histories, and cross-agent context windows.
*Why it matters for practitioners:* In multi-agent deployments, redundant KV recomputation is a major and often overlooked cost driver; TokenPilot is a drop-in architecture that addresses it systematically.

**DLite: History-free Speculative Decoding for Agentic AI** — https://huggingface.co/papers
Decouples speculative decoding from accumulated session history, enabling fast inference for agents that frequently reset context, spawn fresh subagents, or operate in stateless pipelines.
*Why it matters for practitioners:* Standard speculative decoding assumes long, stable context—an assumption agentic workloads routinely violate; this paper adapts the technique to the actual inference patterns of agent systems.

**Route-and-Generate (Rouge): Hierarchical Adaptive Reasoning Training for LLMs** — https://arxiv.org/list/cs.AI/recent
A training framework that teaches LLMs to dynamically decide—at inference time—how much chain-of-thought reasoning to apply per input, scaling compute to query difficulty rather than applying a fixed reasoning budget.
*Why it matters for practitioners:* Enables reasoning models that are cheap on routine queries and thorough on hard ones, directly improving cost-efficiency for deployed reasoning agents without a separate routing model.
