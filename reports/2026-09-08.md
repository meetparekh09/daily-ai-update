## Trending Papers

**Compile by Training: Turning Natural-Language Specifications into Local Neural Functions** — https://huggingface.co/papers (#1 this week)
Compiles NL task specifications into small, reusable local neural functions that run without a live LLM call, treating capability deployment as compilation rather than runtime prompting.
*Why it matters for practitioners:* This reframes the "always call the API" assumption — if frequent tasks can be compiled into cheap local functions, inference costs drop dramatically and latency becomes deterministic, a new deployment pattern for high-throughput agent workloads.

**Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments** — https://huggingface.co/papers (#2 this week)
Converts public terminal-agent trajectories into 37,300 training environments; fine-tuning Qwen3.5-27B on this corpus raises single-round performance +11.9 points and multi-round performance +13.8 points.
*Why it matters for practitioners:* Trajectory recycling is now a validated strategy for bootstrapping agent training data at scale — teams with existing agent logs can generate training sets without labeling new examples from scratch.

**CORAL: Towards Autonomous Multi-Agent Evolution for Open-Ended Discovery** — https://arxiv.org/abs/2604.01658
Replaces fixed orchestration with long-running agents that explore, reflect, and collaborate via shared persistent memory, achieving 3–10x improvement rates over evolutionary baselines (accepted COLM 2026).
*Why it matters for practitioners:* Self-evolving agent systems outperform hand-designed orchestration — this challenges the assumption that careful manual coordination is necessary and points toward systems that improve their own coordination strategies autonomously.

**SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training** — https://arxiv.org/pdf/2606.02355
Decomposes long-horizon agent trajectories into skill primitives and applies RL at the skill level rather than the token level, improving sample efficiency for multi-step tool-use tasks.
*Why it matters for practitioners:* Token-level RL fails on sparse-reward long-horizon tasks; skill-level credit assignment is more practical, making it tractable to train agents on real-world multi-step workflows without massive trajectory budgets.

**FreeToken: Edge-Native Mixture-of-Experts Serving for Local Large Models** — https://huggingface.co/papers (published ~August 17, 2026)
Dynamically maps large open-weight MoE models onto heterogeneous local hardware (CPU, GPU, NPU) using adaptive scheduling based on available resources.
*Why it matters for practitioners:* Running frontier-scale MoE models locally without cloud APIs is increasingly viable — FreeToken's heterogeneous scheduling removes the "dedicated GPU cluster" requirement, enabling capable local inference on standard workstations.
