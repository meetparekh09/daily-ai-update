## Trending Papers

**GraphOPD: Graph-Augmented On-Policy Distillation for LLM Agents** — https://arxiv.org/abs/2610.08959
Submitted October 6, 2026; adds graph-structured credit assignment on top of on-policy distillation, addressing sparse reward for multi-step agent tasks.
*Why it matters for practitioners:* Its structural credit signal transfers to tool-integrated reasoning outside its training domain, which is a concrete answer to the generalization problem in agent post-training.

**A Few Teacher Steps Go a Long Way: Cost-Efficient On-Policy Data Augmentation for Agent Post-Training** — https://arxiv.org/abs/2607.04574
Proposes augmenting agent training data with a small number of teacher-generated trajectories on the student's own distribution.
*Why it matters for practitioners:* If you only need a handful of teacher rollouts to meaningfully shift agent behavior, the cost of on-policy distillation drops sharply — this changes the economics of specialized agent fine-tuning.

**ToolLIFT: Lifting Tool-Specific Trajectories into Function-Level Graphs for Generalizable Tool Planning** — https://arxiv.org/abs/2608.03468
Converts tool-use demonstrations into function-level dependency graphs that generalize across unseen tools.
*Why it matters for practitioners:* Agents that can plan with tools they have never been trained on directly would dramatically reduce the data-collection burden for new tool integrations.

**What Must Generalist Agents Remember?** — https://chatpaper.com/paper/300904
From CMU and Georgia Tech (June 2026); proves a separation theorem: agents that succeed across environments cannot rely on only the current observation and must retain domain-relevant information in memory.
*Why it matters for practitioners:* Gives a formal lower bound on what any working memory architecture must support, directly constraining how minimal a memory layer can be in a general-purpose agent.

**AdaMem: Learning What to Remember with Adaptive Memory Policies for Personalized Agents** — https://arxiv.org/abs/2606.21144
Trains an adaptive policy over a personalized agent's memory, learning when to retain, update, or forget specific information.
*Why it matters for practitioners:* Unbounded memory accumulation is a real ops cost; a learned retention policy that knows when to forget is directly deployable in production agent pipelines.
