## Trending Papers

**"Lazy Agents Answer Against Their Own Beliefs: Reinforcement Learning with Verifiable Beliefs Teaches Them to Act on What They Believe"** — https://huggingface.co/papers
A training method that augments the RL reward signal with a belief-verification step, penalizing agents that take actions inconsistent with their stated internal beliefs to reduce belief-action misalignment.
*Why it matters for practitioners:* Agents that act contrary to their own stated reasoning are fundamentally unpredictable in multi-step workflows; this work provides a training recipe that makes agent behavior more internally consistent.

**"RECAP: Persistent Context Graphs for Efficient Memory Compaction in LLM Agents"** — https://arxiv.org/abs/2609.40118
Introduces a graph-structured context compaction method that marks certain records as protected and retains them through summarization passes, evaluated on SWE-Together and Lost-in-Conversation benchmarks.
*Why it matters for practitioners:* Context budget exhaustion is a production failure mode for long-horizon agents; RECAP outperforms flat summarization and KV-eviction baselines and is a concrete drop-in method for extending agent working memory.

**"Measuring and Teaching Language Model Agents to Act on Delayed Consequences"** — https://arxiv.org/abs/2611.28158
Introduces a benchmark and training procedure for agents running multi-day workflows where individual actions have consequences that only become apparent steps or sessions later.
*Why it matters for practitioners:* Most agent evals measure single-turn performance; this work highlights that multi-day agents require a different credit-assignment mechanism during training, which is the next hard problem for real-world deployment.

**"Real-Time Reasoning Training (RRT)"** — https://arxiv.org/list/cs.AI/new
Proposes RRT as a formal class of training techniques that optimize agents for making decisions under real-time latency constraints, covering both the training curriculum and reward shaping needed for time-sensitive action selection.
*Why it matters for practitioners:* Most LLM training ignores wall-clock latency as a constraint; RRT formalizes how to train agents that trade off reasoning depth for speed, directly relevant for agents in interactive or time-critical production settings.

**"Self-Compacting Language Model Agents"** — https://arxiv.org/abs/2606.23525
Equips agents with a context compaction tool and a rubric for when to trigger it, allowing agents to manage their own context window autonomously during long-horizon tasks without fine-tuning or external supervision.
*Why it matters for practitioners:* Autonomous context management removes a manual infrastructure concern from agent harnesses; agents that self-compact can run longer tasks without engineering a separate compaction pipeline.
