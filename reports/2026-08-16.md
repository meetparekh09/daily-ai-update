## Trending Papers

**Cooperative Coevolution for Resource-Constrained Agentic LLM Post-Training** — <https://arxiv.org/abs/2608.02391>
Introduces CoPES, a cooperative evolutionary strategy that post-trains tool-using LLM agents without backpropagation by decomposing the parameter space into lower-dimensional subspaces searched cooperatively, achieving RL-comparable performance with a fraction of the GPU memory.
*Why it matters for practitioners:* Gradient-free full-parameter post-training means teams without large GPU clusters can now fine-tune agent LLMs end-to-end — this directly changes the economics of building specialized, domain-adapted agent models.

**EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning** — <https://arxiv.org/abs/2608.06197>
Trains LLM agents by having the policy alternate between generating tool calls and simulating the environment's responses, jointly optimizing both roles end-to-end from task-success rewards — eliminating the need for real environment rollouts during training.
*Why it matters for practitioners:* Replacing environment interaction with in-weights rehearsal cuts data-collection costs dramatically and opens agent RL training to domains where live environment access is expensive, rate-limited, or dangerous.

**OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution** — <https://arxiv.org/abs/2608.00677>
An open-ended arena with 10,000+ validated stateful scenarios across 50 domains for stress-testing LLM agents through long-horizon attack sequences, with tasks requiring a median of 97 tool calls.
*Why it matters for practitioners:* Current agent safety benchmarks test single-turn behavior; OpenART reveals failure modes that only emerge after dozens of tool calls — a sobering result for anyone deploying production agents in settings with shared, mutable state.

**REDAgentBench: Executable Red Teaming and Faithful Measurement of LLM Agent Systems** — <https://arxiv.org/abs/2608.10669>
An executable framework for autonomously red-teaming LLM agent systems and producing precise, reproducible safety metrics rather than subjective human assessments.
*Why it matters for practitioners:* Executable safety measurement means teams can gate agent deploys on safety properties in CI/CD pipelines, treating agent safety as an automated regression test rather than a one-time manual review.

**Model Discovery Agent: LLM-assisted Bayesian Experiment Design for Data-Efficient Discovery of Mechanistic World Models** — <https://arxiv.org/abs/2608.09696>
Uses an LLM-driven agent to automate Bayesian experiment design, closing the loop from hypothesis generation through experiment execution to belief update without human-in-the-loop intervention.
*Why it matters for practitioners:* The agent-as-scientist pattern demonstrated here — propose experiment, execute, update beliefs, repeat — translates directly to automated hyperparameter search and AutoML workflows where human iteration is the bottleneck.
