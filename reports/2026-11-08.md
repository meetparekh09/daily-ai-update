## Trending GitHub Repositories

**headroomlabs-ai/headroom** — <https://github.com/headroomlabs-ai/headroom>
An open-source context compression layer for AI agents that compresses tool outputs, RAG chunks, logs, and conversation history before they reach the LLM, with lossless retrieval of originals on demand.
*Why it matters for practitioners:* Self-reported 60–95% token reduction on structured data means you can run longer agentic loops at the same cost, or fit more context in a fixed budget—directly addressing the most common per-call expense in production agents.

**infiniflow/ragflow** — <https://github.com/infiniflow/ragflow>
An end-to-end RAG system with deep document parsing, knowledge-graph support, and a full pipeline from ingestion to answer generation, now at ~94k stars.
*Why it matters for practitioners:* Provides a production-tested reference architecture for RAG that handles the messy document-preprocessing and retrieval steps that are typically the first place RAG systems break in practice.

**mem0ai/mem0** — <https://github.com/mem0ai/mem0>

*Why it matters for practitioners:* Drops in as a service or library to give any LLM-backed agent long-term context without stuffing the entire history into the prompt; memory management is the first architectural problem teams hit when moving from demos to deployed agents.

## Trending Papers

**Sparks of Weight-Space Programming** (MIT CSAIL, Nov 2 2026) — <https://www.datacamp.com/blog/weight-space-programming>
MIT CSAIL researchers show that frontier models like GPT-6 Astra can directly read and edit the raw weights of a smaller model to fix a targeted capability gap, achieving a ~6x improvement on MATH-500 for Qwen3.5-0.8B by touching only ~0.016% of its weights.
*Why it matters for practitioners:* Challenges the assumption that model weights are static artifacts requiring full fine-tuning runs; suggests a new class of model-adaptation workflows where a large model surgically corrects a smaller one, potentially replacing targeted SFT for single capability gaps.

**ShiftRAG: Bypassing the Textual Bottleneck via Decoupled Learning and Continuous Soft Tokens** (arXiv:2611.00871, NeurIPS 2026) — <https://arxiv.org/abs/2611.00871>
A RAG architecture that separates the retrieval learning objective from generation using the same LLM backbone, passing retrieved information as continuous soft tokens rather than text to avoid the information loss inherent in converting dense representations back to natural language.
*Why it matters for practitioners:* The "textual bottleneck"—forcing retrieved context back through tokenized text—is a fundamental limitation of current RAG systems; this NeurIPS-accepted work demonstrates that decoupling these learning objectives significantly improves both retrieval and QA without sacrificing the backbone model's general capabilities.

**ACM: Agentic Context Management for Long Horizon Tasks** (arXiv:2607.21503, CMU/Meta) — <https://arxiv.org/abs/2607.21503>
Gives agents explicit context-editing tools so they can autonomously summarize and offload information to external storage while keeping original messages linked by identifiers, plus a post-training pipeline validated on agentic search and coding tasks.
*Why it matters for practitioners:* Treats context management as a first-class learned capability rather than a system-level policy; agents that manage their own memory via trained behaviors outperform those with only system-imposed truncation or summarization, with direct implications for coding and research agents.

**FrontierPhysics: Evaluating Agents for End-to-End Physics Research** (arXiv:2611.06910, Nov 5 2026) — <https://arxiv.org/abs/2611.06910>
A benchmark of 56 end-to-end physics research tasks written by 42 physicists from their own work, covering literature review, planning, experimentation, and manuscript production; best current agent (Claude Opus 5.5) completes only 27.4% of rollouts.
*Why it matters for practitioners:* Manual review of failures found 48% were non-rigorous reasoning and 34% were missing physics intuition, not knowledge gaps—meaning retrieval and context improvements alone won't close the gap, pointing to deeper reasoning deficiencies in current frontier agents.

**A Practitioner's Guide to Multi-turn Agentic Reinforcement Learning** — <https://www.themoonlight.io/review/a-practitioners-guide-to-multi-turn-agentic-reinforcement-learning>
Empirical study on TextWorld, ALFWorld, and SWE-Gym showing that dense turn-level rewards significantly accelerate multi-turn RL training, and that PPO consistently outperforms RLOO and sparse trajectory-level reward formulations for agentic tasks.
*Why it matters for practitioners:* Provides concrete training-recipe guidance—use turn-level credit assignment, not terminal-only rewards—for teams building RL-trained agents, translating what felt like an engineering choice into a principled architectural recommendation.
