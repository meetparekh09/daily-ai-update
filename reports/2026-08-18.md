## Trending Papers

**Latent On-Policy Self-Distillation** — https://arxiv.org/abs/2608.13040
Introduces LOPD, which replaces hand-crafted textual "privileged context" used in on-policy self-distillation with a jointly-optimized learnable latent substrate that provides dense token-level supervision end-to-end during agent training.
*Why it matters for practitioners:* If you're training smaller agent models via distillation, LOPD eliminates the need to engineer privileged reasoning artifacts by hand — the supervision signal learns itself from experience rather than being specified up front.

**OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution** — https://arxiv.org/abs/2608.00677
A red teaming benchmark with 10,000+ validated stateful scenarios across 50 domains drawn from a pool of 500,000+ tools, requiring a median of 97 tool calls per task, plus the EMHA attack algorithm that evolves new attack surfaces automatically across 75 agent-model configurations.
*Why it matters for practitioners:* Standard safety evals test short, static interactions — OpenART stress-tests cumulative risk in long-horizon agent behavior where early state changes compound across 97+ steps, exposing failure modes invisible to conventional benchmarks.

**Building Multi-Task Agentic LLMs via Two-Phase Distillation** — https://arxiv.org/abs/2606.30044
Proposes a two-phase curriculum (behavioral cloning then RL refinement) to distill a single model that generalizes across diverse agent tasks without per-task fine-tuning.
*Why it matters for practitioners:* Getting one model to cover many agent tasks cuts both serving cost and the maintenance burden of managing a fleet of separately fine-tuned checkpoints — this gives a concrete training recipe for doing that.

**Structured Agent Distillation for Large Language Model** — https://arxiv.org/abs/2505.13820
Segments teacher agent trajectories into REASON and ACT spans and applies span-specific losses to compress large LLM-based agents into smaller student models while preserving reasoning fidelity and action consistency.
*Why it matters for practitioners:* It directly targets the inference-cost problem of running large agent models — smaller agents that reason and act like their teacher enable deployment in cost-sensitive or latency-sensitive settings without sacrificing agent behavior.

**Training with Harnesses: On-Policy Harness Self-Distillation for Complex Reasoning** — https://arxiv.org/abs/2605.08741
Shows that training inside a harness scaffold that verifies intermediate reasoning steps and then distilling that harness-guided behavior back into the base model closes much of the gap between supervised and test-time reasoning.
*Why it matters for practitioners:* This is a practical recipe for stronger reasoning without a larger model — the harness does the heavy lifting at train time, and the distilled model inherits it at inference, requiring no runtime scaffold.
