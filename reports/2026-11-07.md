## Trending Papers

**SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization** — https://arxiv.org/abs/2611.08483
Proposes replacing textual chains of thought with latent-space agent swarms to accelerate LLM-guided evolutionary search.
*Why it matters for practitioners:* This challenges the assumption that reasoning must be text-based — if latent swarms outperform CoT on optimization tasks, it opens a new class of non-verbal agent architectures worth watching.

**Spectral and Subspace Dynamics of LoRA in Supervised Fine-Tuning and Reinforcement Learning** — https://arxiv.org/abs/2611.08414
Tracks how LoRA rank utilization and subspace dynamics evolve differently during SFT compared to RL fine-tuning.
*Why it matters for practitioners:* If LoRA adapters behave fundamentally differently under RL (e.g., on-policy distillation), the rank and learning-rate intuitions developed for SFT need revisiting — directly relevant to anyone doing RLHF or RL-based post-training.

**Enhancing Local and Global Structure in Compressed AI Agent Memory** — https://arxiv.org/abs/2611.08341
Demonstrates that current agent memory compression methods preserve local neighborhoods but systematically destroy global structure.
*Why it matters for practitioners:* This is a concrete, measurable failure mode in production agent memory — if global structure collapses, long-horizon planning and cross-session consistency degrade silently, with no obvious error signal.

**StrataFlux: Memory-Hierarchy-Native Low-Bit LLM Inference** — https://arxiv.org/abs/2611.08363
Recovers accuracy lost to aggressive low-bit quantization by exploiting the full memory hierarchy instead of naively offloading activations.
*Why it matters for practitioners:* Better quantization recovery at low bit-widths means smaller models can hit acceptable accuracy on cheaper hardware — a direct cost lever for teams running LLM inference at scale.

**StepBack: Step-Level Error-Localized Resampling for Efficient Test-Time Reasoning** — https://arxiv.org/abs/2611.08403
Identifies reasoning errors at the step level and resamples only from that point forward, reducing test-time compute compared to full-sequence regeneration.
*Why it matters for practitioners:* Targeted resampling directly cuts the cost of test-time scaling for reasoning-heavy agent tasks (code, math) without sacrificing quality — especially relevant as inference-time compute becomes a primary optimization target.
