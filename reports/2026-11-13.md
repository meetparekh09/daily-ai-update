*Why it matters for practitioners:* Provides empirical guidance on agent compute budgeting — parallel small teams beat monolithic scaling by 8–30% at 100 agents, changing the default architectural choice for high-stakes long-horizon tasks.

**On Turn-Level Best-of-N Sampling for Scaling LLM Agents** — https://arxiv.org/abs/2611.06868
Submitted November 4, 2026: a generator-selector framework where one LLM proposes N candidate actions per turn and a second selects the best, achieving 5–10% accuracy gains on long-horizon terminal tasks with off-the-shelf open-weight models.
*Why it matters for practitioners:* No retraining required — a practical inference-time upgrade to any multi-step agent using existing open models as the selector, deployable today.

**ExpWeaver: LLM Agents Learn from Experience via Latent RAG** — https://arxiv.org/html/2606.01041
Enables agents to build and query a latent experience store across episodes without a separate RAG module, matching HRPO accuracy while substantially reducing token usage.
*Why it matters for practitioners:* Points toward agents that self-improve from their own experience rather than requiring human-curated training data, combining persistent memory with token efficiency advantages.

**Seeing Through the Illusion: Test-Time Scaling for World Action Models** — https://arxiv.org/abs/2611.03585
Submitted November 2, 2026: introduces WISE, a pre-execution selector that scores sampled rollouts before execution using a frozen world model, applied to robot manipulation tasks.
*Why it matters for practitioners:* The pre-execution rollout-scoring pattern generalizes beyond robotics — any sequential-decision agent that can simulate or score rollouts can apply this to filter bad actions before execution.

**Self-Consistency Decoding with Step-Level Resampling (NeurIPS 2026)** — https://arxiv.org/list/cs.CL/new
Accepted to NeurIPS 2026: proposes step-level resampling instead of full-chain resampling in test-time reasoning, allowing finer-grained compute allocation during inference.
*Why it matters for practitioners:* Step-level resampling provides better accuracy per token than chain-level majority voting, offering a practical knob for tuning inference-time compute on reasoning-heavy tasks.
