## Trending Papers

**Osprey: Production-Ready Agentic AI for Safety-Critical Control Systems** — https://arxiv.org/abs/2508.15066
A framework for deploying LLM-driven agents in production control rooms at large scientific facilities, organized around a plan-first orchestrator (complete execution plans generated for human review before hardware is touched), a coordination layer managing heterogeneous data flows, and a classifier that dynamically narrows available tools per task.
*Why it matters for practitioners:* This is a real case study of an agent system with hardware-touching consequences—the plan-first design and dynamic tool selection are directly transferable patterns for anyone building high-stakes agentic workflows where partial actions cannot be easily undone.

**Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory** — https://arxiv.org/abs/2608.07169
A training-free framework (AMD) that extracts three complementary memory types—Workflow (task-level strategies), Subtask (behavioral examples), and Function (tool-calling conventions and pitfall patterns)—from successful large-agent trajectories and injects them into small agents at inference time.
*Why it matters for practitioners:* AMD challenges the assumption that capable agents require large models: by treating large-agent traces as a structured memory curriculum, it opens a cost-effective path to deploying small models on agent tasks without the training infrastructure overhead of distillation or fine-tuning.

**What Deserves Memory: Adaptive Memory Distillation for LLM Agents (NEMORI)** — https://arxiv.org/abs/2508.03341
A framework accepted at ACL 2026 that determines what agent experiences deserve long-term retention via prediction error—not hand-crafted heuristics like importance scores or emotional tags—through two cascading modules: Episodic Memory Integration and Semantic Knowledge Distillation.
*Why it matters for practitioners:* NEMORI replaces designer intuition with a data-driven signal for memory selection, meaning the memory system improves with the agent's actual task distribution rather than approximations of what the system designer thought would matter.

**Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning** — https://arxiv.org/abs/2508.19828
A method that applies reinforcement learning to teach agents when to store, retrieve, and use memories, framing memory management as a learnable policy rather than a fixed-strategy component.
*Why it matters for practitioners:* Memory-R1 demonstrates that RLVR-style training, already proven effective for reasoning, transfers to memory management—practitioners investing in RL post-training pipelines can potentially extend the same framework to improve long-horizon agent coherence without a separate memory-specific engineering effort.

**Learn to Memorize: Optimizing LLM-based Agents with Adaptive Memory Framework** — https://arxiv.org/abs/2508.16629
An adaptive memory framework that jointly optimizes what agents remember and how they retrieve it, with controlled experiments quantifying when memory investment compounds with other agent improvements versus when it saturates.
*Why it matters for practitioners:* The saturation analysis gives practitioners a principled basis for deciding how much engineering effort to invest in the memory layer given a specific task and agent configuration, rather than treating memory as uniformly beneficial.
