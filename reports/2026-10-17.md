## Trending Papers

**Sentry: Learning to Recover from LLM Agent Failures at Test Time** — https://arxiv.org/abs/2610.02994
A failure-management layer that detects agent failures at test time, retrieves matched lessons from an external playbook, and updates that playbook on successful recovery—without using task rewards or accessing model weights.
*Why it matters for practitioners:* Beats strong baselines by 37–39% on recovery benchmarks with lessons that transfer to held-out tasks, providing a practical plug-in reliability layer for any deployed agent that requires no retraining.

**Agent-Reflex: Training Interactive Agents to Reflect and Recover from Noisy Tool Feedback** — https://huggingface.co/papers
A training method combining skill discovery, supervised fine-tuning, and on-policy optimization to make agents robust to noisy tool outputs and user corrections, from RUC-NLPIR (202 upvotes on HF).
*Why it matters for practitioners:* Directly targets the most common failure mode in production agentic pipelines—unreliable tool return values—with a training recipe that generalizes to new noise patterns rather than hardcoding recovery heuristics.

**Harness²: Improving Agent Execution Harnesses Through Recursive Task-Level Refinement and Continual Harness-Level Learning** — https://huggingface.co/papers
A Google method that refines agent execution harnesses at both the individual task level and the global harness level, recursively, without modifying model weights (105 upvotes on HF, Oct 9).
*Why it matters for practitioners:* Introduces harness optimization as a first-class engineering lever—distinct from fine-tuning—demonstrating measurable benchmark gains from iterating on the scaffold rather than the model.

**Self-Evolving Agent Harness** — https://huggingface.co/papers
A framework that evolves agent harnesses through feedback-driven revisions and evolutionary optimization while keeping model weights fixed, with theoretical generalization guarantees (Oct 13).
*Why it matters for practitioners:* Makes harness design automatable and theoretically grounded, suggesting that the optimal harness for a task can be learned rather than hand-engineered, which changes how teams should allocate agent development effort.

**Librarian Agents: Training LLMs to Curate Long-Context Workspaces that Anticipate Future Queries** — https://arxiv.org/abs/2610.22273
A training method that teaches LLMs to proactively curate a persistent workspace by retaining information likely to be needed by future queries, submitted Oct 15 (cs.LG, cs.AI, cs.CL).
*Why it matters for practitioners:* Shifts the long-context bottleneck from retrieval quality to workspace curation strategy—closer to how a skilled human assistant manages information—with implications for any agent that operates over long task horizons.
