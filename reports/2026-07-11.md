## Trending Papers

**RaMem: Contextual Reinstatement for Long-term Agentic Memory** — https://arxiv.org/abs/2606.22844
Proposes a framework that turns retrieved memory fragments into contextually verifiable evidence by recovering the episodic conditions under which each memory is valid before passing it to the agent.
*Why it matters for practitioners:* Solves "context collapse" — where a retrieval system surfaces semantically similar memories that are actually from a different situation — yielding average F1 gains of more than 10% across several LLM backbones on long-term memory benchmarks.

**Maestro: Workload-Aware Cross-Cluster Scheduling for LLM-Based Multi-Agent Systems** — https://arxiv.org/abs/2606.12950
A hierarchical scheduling system for LLM multi-agent workloads that predicts per-stage output length and memory usage to drive dynamic model co-location, elastic memory provisioning, and latency-aware routing across GPU clusters.
*Why it matters for practitioners:* Reduces KV-reservation HBM by 67.2% and improves SLO attainment under high contention by 23.6 points — the kind of infra paper you want before scaling a multi-agent system to production traffic.

**Nemotron-Cascade 2: Post-Training LLMs with Cascade RL and Multi-Domain On-Policy Distillation** — https://arxiv.org/abs/2603.19220
NVIDIA's 30B MoE model (3B activated) trained via cascaded RL across reasoning and agentic domains, with on-policy distillation to recover benchmark regressions that emerge during complex RL environments.
*Why it matters for practitioners:* The on-policy distillation technique is directly portable — it recovers the quality degradation that commonly occurs when pushing RL into harder domains, and the paper shows this works at multiple scales across math, code, and agent tasks.

**Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces** — https://arxiv.org/abs/2605.02801
Trains multi-agent LLM systems using traces from real orchestration runs as the reward signal, enabling end-to-end RL over the full multi-agent pipeline rather than individual model calls.
*Why it matters for practitioners:* Makes production orchestration logs directly useful for training — teams already logging agent runs can turn those logs into a training signal without designing synthetic reward functions.

**Self-Evolving Agents with Anytime-Valid Certificates** — https://arxiv.org/abs/2607.00913
Introduces a framework for agents that improve their own behavior during deployment while maintaining statistically valid performance certificates at any stopping point.
*Why it matters for practitioners:* Provides a formal basis for agents that adapt in production without silent regression — the anytime-valid property means you can halt self-improvement at any point and still have a quantified performance guarantee, which is critical for safety-sensitive deployments.
