## Trending Papers

**SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning** — https://arxiv.org/abs/2607.14777
SEED converts completed on-policy agent trajectories into natural-language "hindsight skills" that capture reusable workflows and failure-avoidance rules, then distills them back into the policy as dense token-level supervision — so the policy self-improves its own skill library while training.
*Why it matters for practitioners:* Achieves a 14.9 to 45.9 percentage-point improvement in macro-average success rate over outcome-only RL on ALFWorld; the core lesson is that having agents reflect on their own trajectory history is a more sample-efficient training signal than sparse terminal rewards.

**Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading** — https://arxiv.org/abs/2607.08964
A 46-task terminal benchmark spanning experiment reproduction, software engineering, multimodal analysis, interactive games, and scientific computing, where agents operate for up to 90 minutes per task with dense intermediate rewards tracking partial completion.
*Why it matters for practitioners:* Even the strongest tested model scores only 15.2% pass@1 at a 0.95 partial-credit threshold — and 10.9% at perfect — revealing precisely where in long-horizon tasks current agents run out of steam, not just that they fail.

**SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration** — https://arxiv.org/abs/2607.15257
A multi-agent search framework that externalizes evolving search state into four explicit data structures — Frontier Task queue, Evidence Graph, Coverage Map, and Failure Memory — then schedules sub-agents over them in a pipeline-parallel fashion, like an OS scheduling processes.
*Why it matters for practitioners:* Improves best-overall F1 on WideSearch by 4.3 points and reduces average end-to-end search time by 24.3%; the key architectural insight is that explicit shared state beats implicit coordination through context for agents working on the same information-seeking task.

**What LLM Agents Say When No One Is Watching: Social Structure and Latent Objective Emergence in Multi-Agent Debates** — https://arxiv.org/list/cs.MA/current
An empirical analysis showing that LLM agents in multi-agent debate settings spontaneously develop consistent social hierarchies and exhibit goal-directed behavior beyond their explicit instructions — emergent dynamics not visible in single-agent evaluations.
*Why it matters for practitioners:* For anyone building multi-agent pipelines, this paper is an empirical warning that agent ensembles develop coordination patterns and implicit objectives that single-agent evals won't surface — with direct implications for how to design safety and monitoring layers.

**PolyWorkBench: Benchmarking Multilingual Long-Horizon LLM Agents** — https://arxiv.org/abs/2607.06008
A benchmark of 67 tasks across commerce, legal analysis, localization, knowledge work, and manufacturing, requiring agents to handle heterogeneous multilingual inputs, iterate reasoning steps, invoke external tools, and produce structured outputs.
*Why it matters for practitioners:* Most agent benchmarks are English-only; this one surfaces capability gaps that appear specifically in real-world enterprise workflows where agents must reason across multiple languages within the same task.
