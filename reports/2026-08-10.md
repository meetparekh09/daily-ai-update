## Trending Papers

**Agent Lightning: Train ANY AI Agents with Reinforcement Learning** — https://arxiv.org/abs/2508.03680
Microsoft's framework that formulates agent execution as a Markov decision process, exposes a unified data interface, and introduces LightningRL—a hierarchical RL algorithm with a credit assignment module—so any existing agent can be RL-trained with essentially zero code changes.
*Why it matters for practitioners:* This removes the last major barrier to applying RL to production agents: you no longer need to redesign your agent architecture around training—RL can now be bolted onto what you already have, and you can optimize individual agents inside multi-agent pipelines without touching orchestration logic.

**Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning** — https://arxiv.org/abs/2508.19828
An RL-based framework that trains two specialized agents—a Memory Manager learning structured operations (ADD, UPDATE, DELETE, NOOP) and an Answer Agent that pre-selects relevant memory entries—using PPO and GRPO with only 152 training examples to outperform strong baselines across three benchmarks.
*Why it matters for practitioners:* The finding that 152 labeled QA pairs is enough to train reliable memory management fundamentally changes the cost estimate for building production long-term memory in agents—it's not a data-collection problem, it's an RL training problem.

**What Deserves Memory: Adaptive Memory Distillation for LLM Agents** — https://arxiv.org/abs/2508.03341
A data-driven framework—NEMORI—that decides what agent interactions deserve retention through two cascading modules: Episodic Memory Integration (raw interactions → coherent narratives) and Semantic Knowledge Distillation (prediction-error-guided insight extraction).
*Why it matters for practitioners:* Rather than storing everything or using hand-coded heuristics, NEMORI lets agents learn what's worth remembering based on what actually improves future predictions—a principled alternative to RAG chunking strategies for conversational memory.

**StepPO: Step-Aligned Policy Optimization for Agentic Reinforcement Learning** — https://arxiv.org/abs/2604.18401
A step-level credit assignment method for RL training of multi-step agents that aligns policy optimization to individual trajectory steps rather than episode-level outcomes, improving training signal quality for long-horizon tasks.
*Why it matters for practitioners:* Sparse, end-of-episode rewards are the core reason RL for agents is hard to get working—StepPO provides a concrete, drop-in improvement to credit assignment that directly addresses why your RL training might be stalling on longer agent tasks.

**SFT-then-RL Outperforms Mixed-Policy Methods for LLM Reasoning** — https://arxiv.org/abs/2604.23747
An empirical study showing that the standard two-phase curriculum—supervised fine-tuning first, RL second—consistently outperforms methods that mix on-policy and off-policy data during joint training, across multiple reasoning benchmarks.
*Why it matters for practitioners:* If you're designing a post-training pipeline and considering whether to mix SFT and RL objectives, this paper gives a clear empirical answer: don't—phase them, and the ordering matters as much as the method.
