## Trending Papers

**"Do LLM Agents Still Need to Be Told How to Self-Improve?"** — https://arxiv.org/abs/2611.23219
Published November 17, 2026 — demonstrates that capable frozen LLM agents can autonomously construct their own context-based self-learning algorithms from basic resources and a general goal, without explicit self-improvement instructions.
*Why it matters for practitioners:* If agents derive their own improvement strategies unprompted, the design assumption that you need to hand-specify a self-improvement loop no longer holds — this reshapes how you think about meta-learning scaffolding for agent systems.

**SWE-Trail: History-Guided Trajectory Collection for Coding Agent Training** — https://arxiv.org/abs/2611.02074
Uses prior trajectory history to direct where new training data collection effort is spent, improving a 124B model's SWE-bench Multilingual resolution by 2.33 percentage points over independent sampling.
*Why it matters for practitioners:* Smarter trajectory collection — not more computation — drives measurable benchmark gains, which is immediately actionable for teams building coding agent training pipelines.

**Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training** — https://huggingface.co/papers
A community-upvoted paper (149 upvotes on HF) that trains agents by exposing them to sibling harness variants, improving generalization across harness configurations rather than overfitting to a single task scaffold.
*Why it matters for practitioners:* Agents deployed in the real world run across different tool versions and harness layouts — training on harness diversity directly addresses distribution shift at deploy time.

**Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent** — https://arxiv.org/abs/2611.18397
From Shanghai AI Lab — pre-trains on tens of thousands of hours of device-level keyboard/mouse interaction and uses Temporal-Aware GRPO for learning from long-horizon game feedback.
*Why it matters for practitioners:* Temporal-Aware GRPO is a concrete RLHF adaptation for long-horizon action sequences where reward is sparse and delayed — directly transferable to any agent working over multi-step workflows.

**QVal: Dense Supervision Signals for Long-Horizon LLM Agents** — https://arxiv.org/list/cs.AI/new
Introduces dense intermediate value estimates along a long-horizon agent trajectory, reducing the sparse-reward problem that slows convergence in multi-step agent training.
*Why it matters for practitioners:* Dense signals at intermediate steps make training long-horizon agents dramatically cheaper; this is the same kind of data efficiency gain that curriculum learning brought to supervised fine-tuning.
