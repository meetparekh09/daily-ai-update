## Trending Papers

**"Self-Evolving Agent Harnesses" (arXiv:2610.18813)** — https://arxiv.org/abs/2610.18813
Formalizes harness self-evolution — where an agent revises its own scaffolding (prompts, memory, workflows, executable components) without touching model weights — and characterizes it with continual PAC-learning theory.
*Why it matters for practitioners:* This is a theoretically grounded treatment of a pattern many teams are implementing ad-hoc; the PAC-learning framing gives a principled way to reason about when harness updates are reliable vs. overfitted.

**"LLM Agents for Automated Post-Training via Structured Recipe Optimization" (arXiv:2610.18572)** — https://arxiv.org/abs/2610.18572
Uses LLM agents to design and optimize post-training pipelines across data sourcing, mixing, and training configuration, reporting 41.1 vs. 15.4 baseline on Qwen3-1.7B across six benchmarks.
*Why it matters for practitioners:* Automates the most labor-intensive part of custom model development; if the results generalize, it changes the cost model for fine-tuning to your domain.

**"Training LLMs for Multi-Agent Collaboration with Verifiable Information Rewards" (arXiv:2610.17893)** — https://arxiv.org/abs/2610.17893
Proposes a training objective for teaching LLMs to collaborate across a multi-agent system, using verifiable rewards derived from the information exchanged between agents rather than just task outcomes.
*Why it matters for practitioners:* Verifiable rewards let you train agent collaboration without needing human labels on intermediate coordination steps — a practical unlock for teams training custom multi-agent systems.

**"ANTE: Anticipate, Then Execute"** — https://huggingface.co/papers
Proposes training coding agents to build internal world models from verified beliefs before taking actions, rather than acting on each token greedily.
*Why it matters for practitioners:* If agents that "think ahead" outperform reactive ones on software engineering tasks, this shifts the design target for coding agent architectures from action-prediction to belief-state maintenance.

**"Understanding and Enhancing Backdoor Persistency in LLM Agent Post-Training" (arXiv:2610.07510)** — https://arxiv.org/abs/2610.07510
Shows that backdoors injected into base models survive both supervised fine-tuning and RL-based post-training in software-engineering agents, and proposes PersistBD to make them even harder to remove.
*Why it matters for practitioners:* Anyone fine-tuning third-party base models for agent use needs to treat supply-chain backdoor persistence as a concrete, verified threat — not a theoretical one.

*Why it matters for practitioners:* The best model scores only 65% on first attempt and 25% across 20 attempts — the gap between agent self-report and ground-truth completion is large, and this benchmark gives you a concrete way to measure it.

*Why it matters for practitioners:* The threat model here isn't agent escape; it's cross-agent influence through legitimate channels, which sandboxing doesn't address — a gap with concrete implications for multi-agent system design.

**"UltraBERT: One Encoder for Classification and Retrieval"** — https://huggingface.co/blog/dmis-lab/ultrabert

*Why it matters for practitioners:* Maintaining separate encoders for retrieval and classification in RAG pipelines adds ops overhead; a single model that matches or beats dedicated encoders on both tasks simplifies architecture without sacrificing performance.
